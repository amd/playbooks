# Playbook Translations

This directory holds **automatically generated** localized copies of the
playbooks. It is a set of **mirrored locale overlays** on top of the English
source of truth in [`playbooks/`](../playbooks/).

> [!IMPORTANT]
> Do not hand-edit files under `translations/`. They are regenerated by the
> [`translate-playbooks.yml`](../.github/workflows/translate-playbooks.yml)
> workflow. Manual edits will be overwritten the next time the source English
> playbook changes.

## Principles

1. **English is the single canonical, executable source.** Only `playbooks/`
   is run and tested by CI. Translations are documentation overlays and are
   never executed or tested.
2. **Prose only is translated.** Code blocks, the special HTML-comment tags
   (`@os`, `@device`, `@require`, `@setup`, `@test`, `@github-only`, ...),
   Markdown/link URLs, image paths, and `playbook.json` keys are preserved
   byte-for-byte so nothing breaks.
3. **Assets are referenced, not duplicated.** Translated pages point back to the
   English `assets/` folder.
4. **Translate once per merge.** When an English playbook changes on `main`, the
   workflow retranslates just that playbook and direct-pushes the result.

## Layout

```text
translations/
  <locale>/                                  # BCP-47 code, e.g. zh-CN, es-LA, fr-FR
    playbooks/
      core/<id>/README.md                    # translated prose (mirrors playbooks/core/<id>/README.md)
      core/<id>/platform.md
      supplemental/<id>/README.md
    metadata/<id>.json                        # translated title + description only
    website.json                              # UI strings / nav labels (added as needed)
    _manifest.json                            # per-file source SHA + hash for staleness tracking
```

The path of a translated file mirrors its English source exactly, only prefixed
with `translations/<locale>/`. For example:

| English source | Translated (`zh-CN`) |
|----------------|----------------------|
| `playbooks/core/comfyui-image-gen/README.md` | `translations/zh-CN/playbooks/core/comfyui-image-gen/README.md` |
| `playbooks/core/comfyui-image-gen/platform.md` | `translations/zh-CN/playbooks/core/comfyui-image-gen/platform.md` |
| `title`/`description` in `playbooks/core/comfyui-image-gen/playbook.json` | `translations/zh-CN/metadata/comfyui-image-gen.json` |

## Supported locales (pilot)

| Locale | Language |
|--------|----------|
| `zh-CN` | Chinese (Simplified) |
| `es-LA` | Spanish (Latin America) |
| `fr-FR` | French |

Additional locales from the Lenovo localization requirements will be added over
time by extending the `locales` input of the workflow.

## Staleness

Each `_manifest.json` records the source file's content hash at translation time.
If an English source changes but its translation was not regenerated, the entry
is considered **stale** and the translation is re-run on the next workflow pass.
The website falls back to English for any page that is missing or stale.
