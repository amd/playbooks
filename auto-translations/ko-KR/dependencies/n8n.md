### n8n

<!-- @os:windows -->

1. PowerShell 또는 명령 프롬프트 열기
2. npm을 사용하여 n8n을 전역으로 설치합니다:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

npm을 사용하여 n8n을 전역으로 설치합니다:
```bash
npm install -g n8n
```

> **참고**: 더 많은 설치 옵션은 [n8n 문서](https://docs.n8n.io/hosting/installation/npm/)를 참조하세요.

<!-- @os:end -->
