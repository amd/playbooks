# Конфігурація платформи

У цьому документі описано очікувані конфігурації платформи для запуску цього playbook.

## Необхідні додатки/фреймворки

### Windows/Linux

GAIA має бути попередньо встановлено за інструкціями, наведеними в [посібнику зі встановлення GAIA](../../dependencies/gaia.md).

Lemonade Server має бути попередньо встановлено за інструкціями, наведеними в [посібнику зі встановлення Lemonade](../../dependencies/lemonade.md).

## Необхідні моделі

### Windows/Linux

Агент Hardware Advisor Agent використовує **Qwen3-Coder-30B** для міркувань агента. Ця модель завантажується автоматично під час виконання `gaia init`. Ручне завантаження моделей не потрібне.
