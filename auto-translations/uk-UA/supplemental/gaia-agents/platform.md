# Конфігурація платформи

Цей документ описує очікувані конфігурації платформи для запуску цього playbook.

## Необхідні застосунки/фреймворки

### Windows/Linux

GAIA має бути попередньо встановлена відповідно до інструкцій, наведених у [Посібнику з встановлення GAIA](../../dependencies/gaia.md).

Lemonade Server має бути попередньо встановлений відповідно до інструкцій, наведених у [Посібнику з встановлення Lemonade](../../dependencies/lemonade.md).

## Необхідні моделі

### Windows/Linux

Агент апаратного консультанта використовує **Qwen3-Coder-30B** для міркувань агента. Ця модель завантажується автоматично під час виконання `gaia init`. Ручне завантаження моделей не потрібне.
