# Конфігурація платформи

У цьому документі описано очікувані конфігурації платформи для виконання цього playbook.

## Необхідні застосунки/фреймворки

### Windows/Linux

- **Lemonade Server** має бути встановлено відповідно до
  [посібника зі встановлення Lemonade](https://lemonade-server.ai/docs/guide/install/).
- **Node.js 22.12 або новіша версія** та `npm`, які використовуються CLI `agent-canvas` та MCP
  серверами, що запускаються за допомогою `npx`.
- **uv** — менеджер пакунків Python, який Agent Canvas використовує для керування середовищем
  сервера агента. Встановіть його з
  [посібника зі встановлення uv](https://docs.astral.sh/uv/getting-started/installation/).

## Необхідні моделі

### Windows/Linux

Наведена нижче модель має бути доступна для Lemonade Server перед запуском
playbook.

| Тип моделі | ID моделі | Примітки |
| --- | --- | --- |
| Чат-модель GGUF | `Qwen3.6-35B-A3B-GGUF` | Обслуговується Lemonade Server за адресою `http://127.0.0.1:13305/api/v1`. Використовуйте меншу модель GGUF на пристроях із менш ніж 32 ГБ пам'яті. |

Запустіть модель за допомогою:

```bash
lemonade config set llamacpp.backend=vulkan
lemonade config set ctx_size=65536
lemonade run "Qwen3.6-35B-A3B-GGUF"
```

## Зовнішні облікові дані

Для цього playbook потрібні:

- Токен GitHub з доступом на читання до репозиторію, що узагальнюється.
- Токен бота Slack з правами `chat:write` та доступом на читання каналу.
- ID команди Slack та ID цільового каналу Slack.
