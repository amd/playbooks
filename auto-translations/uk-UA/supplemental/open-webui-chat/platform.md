# Конфігурація платформи

Цей документ описує очікувану конфігурацію платформи для виконання цього playbook.

## Необхідні застосунки/фреймворки

### Windows/Linux
Lemonade має бути попередньо встановлено [звідси](https://lemonade-server.ai/install_options.html). 

- **Open WebUI** (фронтенд веб-застосунок)
- **Lemonade Server** (бекенд-сервер моделей)

> Цей playbook запускає **Lemonade** (сервер/застосунок Lemonade) **нативно**. **Open WebUI** працює як **контейнер** у Linux (через Podman) і як **Python-пакет** у Windows. Пакет `open-webui` з PyPI підтримує лише Python ≤ 3.12, тому контейнер для Linux дозволяє уникнути необхідності керувати старішими версіями Python.  

## Моделі (у Lemonade)

Моделі слід завантажувати всередині **застосунку Lemonade** (за допомогою вбудованого Model Manager) або через команди керування моделями Lemonade (`lemonade pull <model_name>`). Цей playbook передбачає, що наведені нижче рекомендовані моделі завантажено і вони відображаються в кінцевій точці списку моделей.

Перевірка доступності моделей:
- Відкрийте: `http://localhost:13305/api/v1/models`
- Завантажені моделі будуть перелічені в `"data"`.

### Рекомендовані моделі

| Можливість | ID моделі | Примітки |
|---|----|-----|
| LLM (Текст на вході → Текст на виході) | `Qwen3-4B-Hybrid` (або подібна) | Будь-яка LLM-модель Lemonade для чату, доповнення тексту, кодування або міркувань |
| VLM (Зображення → Текст) | `Qwen3.5-4B-GGUF` (або будь-яка модель у категорії **Vision**) | Будь-яка мультимодальна модель із підтримкою зору, яка може приймати зображення як частину вхідних даних |
| Генерація зображень (Текст → Зображення) | `SDXL-Turbo` (або будь-яка модель у категорії **Image**) | Будь-яка модель Stable Diffusion, яка генерує зображення за текстовим запитом |
| Аудіо (Мовлення → Текст) | `Whisper-Large-v3` (або будь-яка модель у категорії **Audio**) | Будь-яка ASR-модель, яка перетворює аудіо на текст |

## Використовувані порти

- **Lemonade Server:** `http://localhost:13305`

Якщо ці порти вже використовуються у вашій системі, змініть їх під час запуску сервера(ів).
