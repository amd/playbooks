# Конфігурація платформи

Цей документ описує очікувану конфігурацію платформи для запуску цього посібника.

## Необхідні застосунки/фреймворки

### Windows/Linux
Lemonade має бути попередньо встановлено звідси [тут](https://lemonade-server.ai/install_options.html).

- **Open WebUI** (фронтенд веб-застосунок)
- **Lemonade Server** (бекенд сервер моделей)

> Цей посібник запускає **Lemonade** (сервер/застосунок Lemonade) **нативно**. **Open WebUI** запускається як **контейнер** на Linux (через Podman) і як **пакет Python** на Windows. Пакет `open-webui` PyPI підтримує лише Python ≤ 3.12, тому контейнер Linux дозволяє уникнути необхідності керувати старішими версіями Python.

## Моделі (у Lemonade)

Моделі слід завантажувати у **застосунку Lemonade** (за допомогою вбудованого менеджера моделей) або через команди керування моделями Lemonade (`lemonade pull <model_name>`). Цей посібник передбачає, що наведені нижче рекомендовані моделі завантажено та відображаються у кінцевій точці списку моделей.

Перевірка доступності моделей:
- Відкрийте: `http://localhost:13305/api/v1/models`
- Завантажені моделі будуть перелічені у розділі `"data"`.

### Рекомендовані моделі

| Можливість | Ідентифікатор моделі | Примітки |
|---|----|-----|
| LLM (текстовий ввід → текстовий вивід) | `Qwen3-4B-Hybrid` (або подібна) | Будь-яка модель Lemonade LLM для чату, завершення тексту, програмування або міркування |
| VLM (зображення → текст) | `Qwen3.5-4B-GGUF` (або будь-яка модель у категорії **Vision**) | Будь-яка мультимодальна/візуальна модель, що може приймати зображення як частину вхідних даних |
| Генерація зображень (текст → зображення) | `SDXL-Turbo` (або будь-яка модель у категорії **Image**) | Будь-яка модель Stable Diffusion, що генерує зображення за текстовим запитом |
| Аудіо (мовлення → текст) | `Whisper-Large-v3` (або будь-яка модель у категорії **Audio**) | Будь-яка модель ASR, що перетворює аудіо на текст |

## Використовувані порти

- **Lemonade Server:** `http://localhost:13305`
- **Open WebUI:** `http://localhost:8080`

Якщо ці порти вже використовуються у вашій системі, змініть їх під час запуску сервера(ів).
