# Конфігурація платформи — Lemonade Local AI

Цей документ описує попередньо встановлене програмне забезпечення, шляхи до моделей та передумови для конкретної платформи, які передбачаються цим посібником.

## Попередньо встановлене програмне забезпечення

| Програмне забезпечення | Версія | Призначення |
|----------|---------|---------|
| Lemonade Server | Остання версія | Локальний LLM-сервер із OpenAI-сумісним API |
| Python | 3.10–3.13 | Необхідний для прикладу клієнта OpenAI на Python |

## Стандартне місце зберігання моделей

Моделі, завантажені через Lemonade, зберігаються відповідно до специфікації Hugging Face Hub:

| Платформа | Стандартний шлях |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

Щоб змінити місце зберігання, встановіть змінну середовища `HF_HOME`.

## Вимоги до апаратного забезпечення

| Цільове апаратне забезпечення | Вимоги |
|----------------|-------------|
| **CPU** | Будь-який сучасний процесор x86-64 (AMD або Intel) |
| **GPU (Vulkan)** | Будь-який GPU з підтримкою драйвера Vulkan |
| **GPU (ROCm)** | AMD Radeon RX серії 7000/9000 або Radeon PRO W7000 серії; AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | Процесор AMD Ryzen AI серії 300, Windows 11 |

## Вимоги до мережі

- Для початкового завантаження моделі необхідне підключення до інтернету (від 1 до 25 ГБ залежно від моделі)
- Після завантаження моделей інтернет не потрібен
