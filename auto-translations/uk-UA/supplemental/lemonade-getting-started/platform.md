# Конфігурація платформи — Lemonade Local AI

У цьому документі описано попередньо встановлене програмне забезпечення, шляхи до моделей та специфічні для платформи передумови, що передбачаються цим посібником.

## Попередньо встановлене програмне забезпечення

| Програмне забезпечення | Версія | Призначення |
|----------|---------|---------|
| Lemonade Server | Остання версія | Локальний LLM-сервер із сумісним з OpenAI API |
| Python | 3.10–3.13 | Необхідний для прикладу з клієнтом Python OpenAI |

## Стандартне зберігання моделей

Моделі, завантажені через Lemonade, зберігаються відповідно до специфікації Hugging Face Hub:

| Платформа | Стандартний шлях |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

Щоб змінити місце зберігання, встановіть змінну середовища `HF_HOME`.

## Вимоги до апаратного забезпечення

| Апаратна ціль | Вимоги |
|----------------|-------------|
| **CPU** | Будь-який сучасний процесор x86-64 (AMD або Intel) |
| **GPU (Vulkan)** | Будь-який GPU з підтримкою драйвера Vulkan |
| **GPU (ROCm)** | AMD Radeon RX 7000/9000 series або Radeon PRO W7000 series; AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | Процесор AMD Ryzen AI 300 series, Windows 11 |

## Вимоги до мережі

- Для початкового завантаження моделі потрібне підключення до Інтернету (1–25 ГБ залежно від моделі)
- Після завантаження моделей підключення до Інтернету не потрібне
