## Огляд

vLLM — це високопродуктивний движок для інференсу, розроблений для великих мовних моделей (LLM). Він забезпечує оптимізоване обслуговування з безперервним пакетуванням для високої пропускної здатності та сумісний з OpenAI API для безшовної інтеграції з додатками. Це робить vLLM чудовим вибором для промислового розгортання, де швидкість та ефективність використання ресурсів є критично важливими.

Цей посібник навчить вас обслуговувати LLM за допомогою контейнеризованого vLLM на інтегрованому GPU та взаємодіяти з моделями через OpenAI Python API.

## Що ви дізнаєтесь

- Як налаштувати та запустити сервер vLLM з підтримкою AMD ROCm™
- Як взаємодіяти з моделями через сумісні з OpenAI кінцеві точки API
- Як надсилати запити до локального сервера за допомогою `vllm-prompt`

## Встановлення необхідного програмного забезпечення

Цей посібник використовує попередньо зібраний образ контейнера, який включає vLLM, підтримку ROCm та допоміжні скрипти, необхідні для запуску сервера. Вам не потрібно встановлювати PyTorch, vLLM або локальні скрипти посібника вручну.

Кроку встановлення vLLM на хості немає. Запустіть vLLM за допомогою:

```bash
vllm-launch
```

Цей інструмент запуску запускає контейнер, націлюється на інтегрований GPU та надає локальний сумісний з OpenAI сервер vLLM. Альтернативно, натисніть на іконку vLLM на панелі завдань.

## Швидкий старт

### 1. Перевірте, що сервер vLLM працює

`vllm-launch` може зайняти кілька хвилин для ініціалізації всього. Після запуску сервер буде доступний за адресою `http://localhost:8001`. Тримайте термінал запуску відкритим, оскільки сервер працює на передньому плані, потім відкрийте окремий термінал для решти кроків. У прикладах нижче використовується `Qwen/Qwen3-1.7B`; якщо ваш інструмент запуску налаштований для іншої моделі, замініть цей ідентифікатор моделі у запитах.

### 2. Надішліть запит

Використайте наданий скрипт `vllm-prompt`, щоб надіслати запит до локального сервера vLLM, сумісного з OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Спілкування з моделлю за допомогою OpenAI Python API

Оскільки vLLM надає сумісний з OpenAI API, ви можете використовувати пакет Python `openai` для взаємодії з ним.

Спочатку створіть віртуальне середовище Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Встановіть пакет OpenAI
```bash
pip install openai
```

Створіть клієнт `OpenAI`, спрямований на локальний сервер vLLM замість серверів OpenAI. Клієнту потрібен `api_key`, але vLLM не перевіряє його, тому підійде будь-який рядок:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Потім надішліть запит на завершення чату. Тут використовується той самий формат повідомлень, що й у API OpenAI — список повідомлень з ролями, такими як `"user"` та `"assistant"`. Встановлення `stream=True` означає, що відповідь надходитиме поступово, а не вся одразу:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Нарешті, пройдіться по потокових фрагментах та виведіть кожен фрагмент тексту у міру його надходження:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Включений скрипт [chat_with_model.py](assets/chat_with_model.py) містить весь приклад і може бути завантажений.
