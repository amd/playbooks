## Огляд

vLLM — це високопродуктивний механізм інференсу, розроблений для великих мовних моделей (LLM). Він забезпечує оптимізоване обслуговування з безперервним пакетуванням (continuous batching) для високої пропускної здатності та сумісний з OpenAI API для безшовної інтеграції з застосунками. Це робить vLLM чудовим вибором для промислового розгортання, де важливі швидкість та ефективність використання ресурсів.

Цей посібник навчить вас обслуговувати LLM за допомогою контейнеризованого vLLM на інтегрованому GPU та взаємодіяти з моделями через OpenAI Python API.

## Що ви дізнаєтеся

- Як налаштувати та запустити сервер vLLM з підтримкою AMD ROCm™
- Як взаємодіяти з моделями через кінцеві точки, сумісні з OpenAI API
- Як надсилати запити до локального сервера за допомогою `vllm-prompt`

## Встановлення необхідного програмного забезпечення

vLLM працює у попередньо зібраному контейнері з ROCm та узгодженими залежностями. Додаткове встановлення не потрібне.

Кроку встановлення vLLM на хості немає. Запустіть vLLM за допомогою:

```bash
vllm-launch
```

Засіб запуску запускає контейнер, спрямовує роботу на інтегрований GPU та надає локальний сервер vLLM, сумісний з OpenAI API. Альтернативно натисніть на піктограму vLLM на панелі задач.

## Швидкий старт

### 1. Переконайтеся, що сервер vLLM працює

Команді `vllm-launch` може знадобитися кілька хвилин, щоб усе ініціалізувати. Після запуску сервер стає доступним за адресою `http://localhost:8001`. Залиште термінал запуску відкритим, оскільки сервер працює на передньому плані, а для решти кроків відкрийте окремий термінал. У наведених нижче прикладах використовується `Qwen/Qwen3-1.7B`; якщо ваш засіб запуску налаштований на іншу модель, замініть відповідний ідентифікатор моделі у запитах.

### 2. Надішліть запит

Використайте наданий скрипт `vllm-prompt`, щоб надіслати запит до локального сервера vLLM, сумісного з OpenAI API:

```bash
vllm-prompt "Tell me a story"
```

### 3. Спілкування з моделлю за допомогою OpenAI Python API

Оскільки vLLM надає API, сумісний з OpenAI, ви можете використовувати пакет `openai` для Python для взаємодії з ним.

Спочатку створіть віртуальне середовище Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Встановіть пакет OpenAI
```bash
pip install openai
```

Створіть клієнт `OpenAI`, спрямований на локальний сервер vLLM замість серверів OpenAI. Клієнту потрібен `api_key`, але vLLM його не перевіряє, тому підійде будь-який рядок:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Потім надішліть запит на завершення чату. Тут використовується той самий формат повідомлень, що й у API OpenAI — список повідомлень із ролями, такими як `"user"` та `"assistant"`. Встановлення `stream=True` означає, що відповідь надходитиме поступово, а не вся одразу:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Насамкінець переберіть фрагменти потоку та виведіть кожну частину тексту одразу після її надходження:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Скрипт [chat_with_model.py](assets/chat_with_model.py), що додається, містить повний приклад і доступний для завантаження.


## Вибір і налаштування моделі

За замовчуванням `vllm-launch` обслуговує `Qwen/Qwen3-1.7B` як тестову модель на порту `8001`. Ви можете змінити модель, порт та параметри обслуговування vLLM без перезбирання чи редагування контейнера.

### Моделі, протестовані AMD

Наступні моделі попередньо налаштовані та перевірені AMD:

| Модель | Примітки |
|-------|-------|
| `Qwen/Qwen3-1.7B` | Модель за замовчуванням. Легка та швидко завантажується. |
| `openai/gpt-oss-20b` | Більша модель для отримання відповідей вищої якості. |

### Запуск іншої моделі

Передайте ідентифікатор моделі за допомогою `--model` (або `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### Зміна порту

Передайте порт вище 1024 за допомогою `--port` (або `-p`); за замовчуванням використовується `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

Якщо ви змінили порт, вкажіть у `base_url` вашого клієнта той самий порт (наприклад, `http://localhost:8080/v1`).

### Передача додаткових параметрів vLLM

Будь-які додаткові аргументи передаються безпосередньо в vLLM, тому ви можете налаштовувати поведінку обслуговування, наприклад довжину контексту чи тип даних. Є два способи їх передати.

**Убудовано (inline)**, після параметрів засобу запуску:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**Постійно**, у файлі конфігурації за шляхом `~/.local/share/vLLM/vllm-launch.conf`. Цей файл не існує за замовчуванням — створіть його та додайте свої аргументи у вигляді масиву Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

Використовуйте `+=`, щоб додати аргументи до значень за замовчуванням, а не замінювати їх:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

Щоб у будь-який момент переглянути всі параметри засобу запуску, виконайте:

```bash
vllm-launch --help
```

### Де зберігаються моделі

`vllm-launch` шукає моделі у двох місцях:

| Розташування | Шлях |
|----------|------|
| Системні моделі | `/var/cache/models` |
| Моделі користувача | `~/.local/share/vLLM/models` |

Ви можете розмістити завантажену модель у будь-якому з цих каталогів та запустити її, передавши її шлях або ідентифікатор до `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **Примітка**: очікується, що запуск власної завантаженої моделі таким способом працюватиме, щойно модель буде розміщено в одному з наведених вище каталогів, проте цей робочий процес ще не був офіційно перевірений AMD.

## Підсумок

У цьому посібнику ви навчилися:

- Запускати контейнеризований vLLM з підтримкою ROCm на інтегрованому GPU
- Запускати сервер vLLM із кінцевими точками API, сумісними з OpenAI, на порту 8001
- Надсилати запити за допомогою `vllm-prompt`
- Робити виклики API до сервера vLLM, використовуючи як потокові, так і непотокові запити
- Усувати поширені проблеми із запуском сервера, пам'яттю та з'єднаннями клієнтів

Тепер у вас є контейнеризоване розгортання vLLM для обслуговування великих мовних моделей з оптимізованою продуктивністю на інтегрованому GPU.

## Наступні кроки

- **Спробуйте різні моделі** — використовуйте `vllm-launch --model <model>`, щоб експериментувати з різними LLM та порівнювати продуктивність (див. [Вибір і налаштування моделі](#choosing-and-configuring-a-model)).
- **Створіть застосунок** — використовуйте API, сумісний з OpenAI, щоб інтегрувати vLLM у застосунок Python, чат-бота або робочий процес автоматизації.
- **Донавчання та обслуговування** — донавчіть модель за допомогою LoRA або QLoRA, а потім розгорніть її з vLLM для оптимізованого інференсу.
