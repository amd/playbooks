## Огляд

vLLM — це високопродуктивний механізм виведення, розроблений для великих мовних моделей (LLM). Він забезпечує оптимізоване обслуговування з безперервним пакетуванням для високої пропускної здатності та OpenAI-сумісний API для безперешкодної інтеграції з додатками. Завдяки цьому vLLM чудово підходить для виробничих розгортань, де критично важливі швидкість і ефективне використання ресурсів.

Цей посібник навчить вас, як обслуговувати LLM за допомогою контейнеризованого vLLM на інтегрованому GPU та взаємодіяти з моделями через OpenAI Python API.

## Що ви дізнаєтесь

- Як налаштувати та запустити сервер vLLM з підтримкою AMD ROCm™
- Як взаємодіяти з моделями через OpenAI-сумісні кінцеві точки API
- Як надсилати запити до локального сервера за допомогою `vllm-prompt`

## Встановлення необхідного програмного забезпечення

Цей посібник використовує попередньо зібраний образ контейнера, який включає vLLM, підтримку ROCm та допоміжні скрипти, необхідні для запуску сервера. Вам не потрібно вручну встановлювати PyTorch, vLLM або локальні скрипти посібника.

Крок встановлення vLLM на стороні хоста відсутній. Запустіть vLLM за допомогою:

```bash
vllm-launch
```

Засіб запуску стартує контейнер, націлюється на інтегрований GPU та надає локальний OpenAI-сумісний сервер vLLM. Крім того, можна натиснути значок vLLM на панелі завдань.

## Швидкий старт

### 1. Підтвердіть, що сервер vLLM запущено

Ініціалізація `vllm-launch` може зайняти кілька хвилин. Після запуску сервер доступний за адресою `http://localhost:8001`. Залиште термінал запуску відкритим, оскільки сервер працює на передньому плані, а потім відкрийте окремий термінал для виконання наступних кроків. У наведених нижче прикладах використовується `Qwen/Qwen3-1.7B`; якщо ваш засіб запуску налаштовано для іншої моделі, підставте відповідний ідентифікатор моделі у запитах.

### 2. Надішліть запит

Використовуйте наданий скрипт `vllm-prompt` для надсилання запиту до локального OpenAI-сумісного сервера vLLM:

```bash
vllm-prompt "Tell me a story"
```

### 3. Спілкуйтесь з моделлю за допомогою OpenAI Python API

Оскільки vLLM надає OpenAI-сумісний API, ви можете використовувати пакет Python `openai` для взаємодії з ним.

Спочатку створіть віртуальне середовище Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Встановіть пакет OpenAI
```bash
pip install openai
```

Створіть клієнт `OpenAI`, що вказує на локальний сервер vLLM замість серверів OpenAI. `api_key` вимагається клієнтом, але vLLM його не перевіряє, тому підійде будь-який рядок:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Потім надішліть запит на завершення чату. Він використовує той самий формат повідомлень, що й OpenAI API — список повідомлень з ролями, такими як `"user"` та `"assistant"`. Встановлення `stream=True` означає, що відповідь надходитиме поступово, а не вся одразу:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Нарешті, виконайте ітерацію по потокових фрагментах і виводьте кожну частину тексту в міру її надходження:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Доданий скрипт [chat_with_model.py](assets/chat_with_model.py) містить повний приклад і може бути завантажений.
