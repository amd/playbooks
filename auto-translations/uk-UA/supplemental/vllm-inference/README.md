## Огляд

vLLM — це високопродуктивний інференс-рушій, розроблений для великих мовних моделей (LLM). Він забезпечує оптимізоване обслуговування з безперервним пакетуванням (continuous batching) для високої пропускної здатності та сумісний з OpenAI API для безшовної інтеграції додатків. Це робить vLLM чудовим вибором для промислового розгортання, де критично важливі швидкість та ефективність використання ресурсів.

Цей посібник навчить вас обслуговувати LLM за допомогою контейнеризованого vLLM на інтегрованому GPU та взаємодіяти з моделями через OpenAI Python API.

## Чого ви навчитеся

- Як налаштувати та запустити сервер vLLM з підтримкою AMD ROCm™
- Як взаємодіяти з моделями через сумісні з OpenAI API-кінцеві точки
- Як надсилати запити до локального сервера за допомогою `vllm-prompt`

## Встановлення необхідного програмного забезпечення

vLLM працює у попередньо зібраному контейнері з ROCm та узгодженими залежностями. Додаткове встановлення не потрібне.

Кроку встановлення vLLM на хості немає. Запустіть vLLM за допомогою:

```bash
vllm-launch
```

Засіб запуску стартує контейнер, націлюється на інтегрований GPU та відкриває локальний сумісний з OpenAI сервер vLLM. Альтернативно, натисніть на значок vLLM на панелі задач.

## Швидкий старт

### 1. Переконайтеся, що сервер vLLM запущено

Команда `vllm-launch` може зайняти кілька хвилин для ініціалізації всього необхідного. Після запуску сервер буде доступний за адресою `http://localhost:8001`. Залиште термінал запуску відкритим, оскільки сервер працює на передньому плані, а для решти кроків відкрийте окремий термінал. У прикладах нижче використовується `Qwen/Qwen3-1.7B`; якщо ваш засіб запуску налаштовано на іншу модель, замініть цей ідентифікатор моделі у запитах.

### 2. Надішліть запит

Скористайтеся наданим скриптом `vllm-prompt`, щоб надіслати запит до локального сумісного з OpenAI сервера vLLM:

```bash
vllm-prompt "Tell me a story"
```

### 3. Спілкування з моделлю за допомогою OpenAI Python API

Оскільки vLLM надає сумісний з OpenAI API, ви можете використовувати пакет Python `openai` для взаємодії з ним.

Спочатку створіть віртуальне середовище Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->
<!-- @os:end -->

Встановіть пакет OpenAI
```bash
pip install openai
```

Створіть клієнт `OpenAI`, що вказує на локальний сервер vLLM замість серверів OpenAI. Параметр `api_key` є обов'язковим для клієнта, але vLLM не перевіряє його, тому підійде будь-який рядок:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Потім надішліть запит на завершення чату. Він використовує той самий формат повідомлень, що й OpenAI API — список повідомлень з ролями на кшталт `"user"` та `"assistant"`. Встановлення `stream=True` означає, що відповідь надходитиме поступово, а не вся одразу:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Насамкінець, перебирайте потокові фрагменти та виводьте кожен шматок тексту по мірі надходження:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Доданий скрипт [chat_with_model.py](assets/chat_with_model.py) містить повний приклад і може бути завантажений.


## Вибір та налаштування моделі

За замовчуванням `vllm-launch` обслуговує `Qwen/Qwen3-1.7B` як тестову модель на порту `8001`. Ви можете змінити модель, порт та параметри обслуговування vLLM без перезбирання чи редагування контейнера.

### Моделі, перевірені AMD

Наступні моделі попередньо налаштовані та перевірені AMD:

| Модель | Примітки |
|-------|-------|
| `Qwen/Qwen3-1.7B` | Модель за замовчуванням. Легка та швидко завантажується. |
| `openai/gpt-oss-20b` | Більша модель для відповідей вищої якості. |

### Запуск іншої моделі

Передайте ідентифікатор моделі за допомогою `--model` (або `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### Зміна порту

Передайте номер порту вище 1024 за допомогою `--port` (або `-p`); за замовчуванням використовується `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

Якщо ви змінюєте порт, вкажіть той самий порт у `base_url` вашого клієнта (наприклад, `http://localhost:8080/v1`).

### Передача додаткових параметрів vLLM

Будь-які додаткові аргументи передаються безпосередньо до vLLM, тому ви можете налаштувати поведінку обслуговування, наприклад довжину контексту або тип даних. Є два способи їх передачі.

**Вбудовано**, після параметрів засобу запуску:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**Постійно**, у файлі конфігурації `~/.local/share/vLLM/vllm-launch.conf`. Цей файл не існує за замовчуванням — створіть його та додайте свої аргументи у вигляді масиву Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

Використовуйте `+=`, щоб додати до стандартних аргументів, а не замінювати їх:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

Щоб у будь-який момент переглянути всі параметри засобу запуску, виконайте:

```bash
vllm-launch --help
```

### Де зберігаються моделі

`vllm-launch` шукає моделі у двох місцях:

| Розташування | Шлях |
|----------|------|
| Системні моделі | `/var/cache/models` |
| Моделі користувача | `~/.local/share/vLLM/models` |

Ви можете розмістити завантажену модель в одному з цих каталогів і запустити її, передавши її шлях або ідентифікатор до `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **Примітка**: Очікується, що запуск власної завантаженої моделі таким чином працюватиме, щойно модель буде розміщено в одному з каталогів вище, однак цей робочий процес ще не був офіційно перевірений AMD.

## Наступні кроки

- **Спробуйте різні моделі** — Використовуйте `vllm-launch --model <model>`, щоб експериментувати з різними LLM та порівнювати продуктивність (див. [Вибір та налаштування моделі](#choosing-and-configuring-a-model)).

- **Доналаштуйте та обслуговуйте** — Доналаштуйте модель за допомогою LoRA або QLoRA, а потім розгорніть її з vLLM для оптимізованого інференсу.
