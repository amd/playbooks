### n8n

<!-- @os:windows -->

1. Åpne PowerShell eller Command Prompt
2. Installer n8n globalt ved hjelp av npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Installer n8n globalt ved hjelp av npm:
```bash
npm install -g n8n
```

> **Merk**: Se [n8n Documentation](https://docs.n8n.io/hosting/installation/npm/) for flere installasjonsalternativer.

<!-- @os:end -->
