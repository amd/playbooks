#### ROCm

**Legg til gjeldende bruker i render- og videogruppene.** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**Start systemet på nytt for å bruke innstillingene.**
```bash
sudo reboot
```

**Installer ROCm i det opprettede virtuelle miljøet.**
> **Merk**: Sørg for at det virtuelle miljøet er aktivt før du fortsetter.
