### n8n

<!-- @os:windows -->

1. 開啟 PowerShell 或命令提示字元
2. 使用 npm 全域安裝 n8n：
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

使用 npm 全域安裝 n8n：
```bash
npm install -g n8n
```

> **注意**：請參閱 [n8n 文件](https://docs.n8n.io/hosting/installation/npm/) 以了解更多安裝選項。

<!-- @os:end -->
