#### ROCm

**將目前使用者加入 render 和 video 群組。** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**重新啟動系統以套用設定。**
```bash
sudo reboot
```

**在建立的虛擬環境中安裝 ROCm。**
> **注意**：請確認在繼續之前虛擬環境已啟用。
