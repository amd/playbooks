### n8n

<!-- @os:windows -->

1. Abra o PowerShell ou a Linha de Comandos
2. Instale o n8n globalmente utilizando o npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Instale o n8n globalmente utilizando o npm:
```bash
npm install -g n8n
```

> **Nota**: Consulte a [Documentação do n8n](https://docs.n8n.io/hosting/installation/npm/) para mais opções de instalação.

<!-- @os:end -->
