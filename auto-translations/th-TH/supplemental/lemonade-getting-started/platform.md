# การกำหนดค่าแพลตฟอร์ม — Lemonade Local AI

เอกสารนี้อธิบายซอฟต์แวร์ที่ติดตั้งไว้ล่วงหน้า เส้นทางของโมเดล และข้อกำหนดเบื้องต้นเฉพาะแพลตฟอร์มที่สมมติไว้ในเพลย์บุ๊กนี้

## ซอฟต์แวร์ที่ติดตั้งไว้ล่วงหน้า

| ซอฟต์แวร์ | เวอร์ชัน | วัตถุประสงค์ |
|----------|---------|---------|
| Lemonade Server | รุ่นล่าสุด | เซิร์ฟเวอร์ LLM ในเครื่องที่มี API แบบเข้ากันได้กับ OpenAI |
| Python | 3.10–3.13 | จำเป็นสำหรับตัวอย่างไคลเอนต์ Python ของ OpenAI |

## ตำแหน่งจัดเก็บโมเดลเริ่มต้น

โมเดลที่ดาวน์โหลดผ่าน Lemonade จะถูกจัดเก็บโดยใช้ข้อกำหนดของ Hugging Face Hub:

| แพลตฟอร์ม | เส้นทางเริ่มต้น |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

หากต้องการเปลี่ยนตำแหน่งจัดเก็บ ให้ตั้งค่าตัวแปรสภาพแวดล้อม `HF_HOME`

## ข้อกำหนดด้านฮาร์ดแวร์

| เป้าหมายฮาร์ดแวร์ | ข้อกำหนด |
|----------------|-------------|
| **CPU** | โปรเซสเซอร์ x86-64 รุ่นใหม่ใดก็ได้ (AMD หรือ Intel) |
| **GPU (Vulkan)** | GPU ใดก็ได้ที่รองรับไดรเวอร์ Vulkan |
| **GPU (ROCm)** | AMD Radeon RX 7000/9000 series หรือ Radeon PRO W7000 series; AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | โปรเซสเซอร์ AMD Ryzen AI 300 series, Windows 11 |

## ข้อกำหนดด้านเครือข่าย

- ต้องมีการเชื่อมต่ออินเทอร์เน็ตสำหรับการดาวน์โหลดโมเดลครั้งแรก (1–25 GB ขึ้นอยู่กับโมเดล)
- ไม่จำเป็นต้องใช้อินเทอร์เน็ตหลังจากดาวน์โหลดโมเดลแล้ว
