# การกำหนดค่าแพลตฟอร์ม — Lemonade Local AI

เอกสารนี้อธิบายซอฟต์แวร์ที่ติดตั้งไว้ล่วงหน้า เส้นทางของโมเดล และข้อกำหนดเบื้องต้นเฉพาะแพลตฟอร์มที่ playbook นี้ใช้งาน

## ซอฟต์แวร์ที่ติดตั้งไว้ล่วงหน้า

| ซอฟต์แวร์ | เวอร์ชัน | วัตถุประสงค์ |
|----------|---------|---------|
| Lemonade Server | รุ่นล่าสุด | เซิร์ฟเวอร์ LLM ในเครื่องพร้อม API ที่เข้ากันได้กับ OpenAI |
| Python | 3.10–3.13 | จำเป็นสำหรับตัวอย่าง OpenAI Python client |

## ที่จัดเก็บโมเดลเริ่มต้น

โมเดลที่ดาวน์โหลดผ่าน Lemonade จะถูกจัดเก็บโดยใช้ข้อกำหนดของ Hugging Face Hub:

| แพลตฟอร์ม | เส้นทางเริ่มต้น |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

หากต้องการเปลี่ยนตำแหน่งที่จัดเก็บ ให้ตั้งค่าตัวแปรสภาพแวดล้อม `HF_HOME`

## ข้อกำหนดด้านฮาร์ดแวร์

| เป้าหมายฮาร์ดแวร์ | ข้อกำหนด |
|----------------|-------------|
| **CPU** | โปรเซสเซอร์ x86-64 สมัยใหม่ทั่วไป (AMD หรือ Intel) |
| **GPU (Vulkan)** | GPU ใดก็ได้ที่รองรับไดรเวอร์ Vulkan |
| **GPU (ROCm)** | AMD Radeon RX ซีรีส์ 7000/9000 หรือ Radeon PRO W7000 ซีรีส์; AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | โปรเซสเซอร์ AMD Ryzen AI 300 ซีรีส์, Windows 11 |

## ข้อกำหนดด้านเครือข่าย

- ต้องการการเชื่อมต่ออินเทอร์เน็ตสำหรับการดาวน์โหลดโมเดลครั้งแรก (1–25 GB ขึ้นอยู่กับโมเดล)
- ไม่ต้องการอินเทอร์เน็ตหลังจากดาวน์โหลดโมเดลแล้ว
