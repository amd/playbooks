## ภาพรวม

vLLM คือเอนจินการอนุมาน (inference engine) ที่มีประสิทธิภาพสูง ออกแบบมาสำหรับโมเดลภาษาขนาดใหญ่ (LLMs) โดยมีการให้บริการที่ผ่านการปรับให้เหมาะสมด้วยการทำ continuous batching เพื่อรองรับปริมาณงานสูง และมี API ที่รองรับ OpenAI สำหรับการผสานรวมกับแอปพลิเคชันได้อย่างราบรื่น สิ่งนี้ทำให้ vLLM เหมาะอย่างยิ่งสำหรับการใช้งานจริง (production deployments) ที่ต้องการความเร็วและประสิทธิภาพการใช้ทรัพยากรที่สำคัญ

เพลย์บุ๊กนี้จะสอนวิธีให้บริการ LLMs โดยใช้ vLLM แบบคอนเทนเนอร์บน GPU ในตัว (integrated GPU) และการโต้ตอบกับโมเดลผ่าน OpenAI Python API

## สิ่งที่คุณจะได้เรียนรู้

- วิธีตั้งค่าและเริ่มต้นเซิร์ฟเวอร์ vLLM ด้วยการรองรับ AMD ROCm™
- วิธีโต้ตอบกับโมเดลผ่านปลายทาง API ที่รองรับ OpenAI
- วิธีส่งพรอมต์ไปยังเซิร์ฟเวอร์ในเครื่องด้วย `vllm-prompt`

## การติดตั้งซอฟต์แวร์ที่จำเป็น

เพลย์บุ๊กนี้ใช้อิมเมจคอนเทนเนอร์ที่สร้างไว้ล่วงหน้า ซึ่งประกอบด้วย vLLM การรองรับ ROCm และสคริปต์ตัวช่วยที่จำเป็นสำหรับการเริ่มต้นเซิร์ฟเวอร์ คุณไม่จำเป็นต้องติดตั้ง PyTorch, vLLM หรือสคริปต์เพลย์บุ๊กในเครื่องด้วยตนเอง

ไม่มีขั้นตอนการติดตั้ง vLLM ฝั่งโฮสต์ ให้เริ่มต้น vLLM ด้วย:

```bash
vllm-launch
```

ตัวเรียกใช้งาน (launcher) จะเริ่มต้นคอนเทนเนอร์ กำหนดเป้าหมายไปที่ GPU ในตัว และเปิดเผยเซิร์ฟเวอร์ vLLM ที่รองรับ OpenAI ในเครื่อง หรืออีกทางเลือกหนึ่ง ให้คลิกที่ไอคอน vLLM บนแถบงาน (taskbar)

## เริ่มต้นใช้งานอย่างรวดเร็ว

### 1. ยืนยันว่าเซิร์ฟเวอร์ vLLM กำลังทำงานอยู่

`vllm-launch` อาจใช้เวลาสองสามนาทีในการเริ่มต้นทุกอย่าง เมื่อเริ่มทำงานแล้ว เซิร์ฟเวอร์จะพร้อมใช้งานที่ `http://localhost:8001` ให้เปิดเทอร์มินัลที่ใช้เริ่มต้นไว้ต่อไป เนื่องจากเซิร์ฟเวอร์ทำงานอยู่เบื้องหน้า (foreground) จากนั้นเปิดเทอร์มินัลแยกต่างหากสำหรับขั้นตอนที่เหลือ ตัวอย่างด้านล่างนี้ใช้ `Qwen/Qwen3-1.7B` หากตัวเรียกใช้งานของคุณถูกกำหนดค่าไว้สำหรับโมเดลอื่น ให้แทนที่ด้วยรหัสโมเดลนั้นในคำขอ

### 2. ส่งพรอมต์

ใช้สคริปต์ `vllm-prompt` ที่ให้มาเพื่อส่งคำขอไปยังเซิร์ฟเวอร์ vLLM ที่รองรับ OpenAI ในเครื่อง:

```bash
vllm-prompt "Tell me a story"
```

### 3. สนทนากับโมเดลโดยใช้ OpenAI Python API

เนื่องจาก vLLM เปิดเผย API ที่รองรับ OpenAI คุณสามารถใช้แพ็กเกจ `openai` ของ Python เพื่อโต้ตอบกับมันได้

ก่อนอื่น ให้สร้างสภาพแวดล้อมเสมือน (virtual environment) ของ Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

ติดตั้งแพ็กเกจ OpenAI
```bash
pip install openai
```

สร้างไคลเอนต์ `OpenAI` ที่ชี้ไปยังเซิร์ฟเวอร์ vLLM ในเครื่องแทนที่จะเป็นเซิร์ฟเวอร์ของ OpenAI `api_key` เป็นสิ่งที่จำเป็นสำหรับไคลเอนต์ แต่ vLLM ไม่ได้ตรวจสอบความถูกต้อง ดังนั้นสตริงใดก็ได้จึงใช้งานได้:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

จากนั้นส่งคำขอ chat completion โดยใช้รูปแบบข้อความเดียวกันกับ OpenAI API ซึ่งเป็นรายการของข้อความที่มีบทบาทต่างๆ เช่น `"user"` และ `"assistant"` การตั้งค่า `stream=True` หมายความว่าคำตอบจะมาถึงแบบทยอย (incrementally) แทนที่จะมาทั้งหมดในครั้งเดียว:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

สุดท้าย ให้วนซ้ำ (iterate) ผ่านชิ้นส่วนที่สตรีมมาและพิมพ์ข้อความแต่ละส่วนออกมาเมื่อมันมาถึง:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

สคริปต์ [chat_with_model.py](assets/chat_with_model.py) ที่ให้มาพร้อมกับเพลย์บุ๊กนี้ประกอบด้วยตัวอย่างทั้งหมดและสามารถดาวน์โหลดได้

## สรุป

ในเพลย์บุ๊กนี้ คุณได้เรียนรู้วิธี:

- เริ่มต้น vLLM แบบคอนเทนเนอร์ที่มีการรองรับ ROCm บน GPU ในตัว
- เริ่มต้นเซิร์ฟเวอร์ vLLM ที่มีปลายทาง API รองรับ OpenAI บนพอร์ต 8001
- ส่งพรอมต์ด้วย `vllm-prompt`
- เรียกใช้ API ไปยังเซิร์ฟเวอร์ vLLM โดยใช้ทั้งคำขอแบบสตรีมและไม่สตรีม
- แก้ไขปัญหาทั่วไปเกี่ยวกับการเริ่มต้นเซิร์ฟเวอร์ หน่วยความจำ และการเชื่อมต่อไคลเอนต์

ขณะนี้คุณมีการติดตั้ง vLLM แบบคอนเทนเนอร์สำหรับให้บริการโมเดลภาษาขนาดใหญ่ ที่มีประสิทธิภาพเหมาะสมบน GPU ในตัวแล้ว

## ขั้นตอนถัดไป

- **ลองใช้โมเดลอื่น** — สลับโมเดลในการกำหนดค่า `vllm-launch` เพื่อทดลองใช้ LLMs ที่แตกต่างกันและเปรียบเทียบประสิทธิภาพ
- **สร้างแอปพลิเคชัน** — ใช้ API ที่รองรับ OpenAI เพื่อผสานรวม vLLM เข้ากับแอป Python, แชทบอท หรือเวิร์กโฟลว์อัตโนมัติ
- **ปรับแต่งและให้บริการ (Fine-tune and serve)** — ปรับแต่งโมเดลโดยใช้ LoRA หรือ QLoRA จากนั้นนำไปใช้งานด้วย vLLM เพื่อการอนุมานที่ผ่านการปรับให้เหมาะสม
