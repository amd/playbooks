## ภาพรวม

vLLM เป็นเอนจินสำหรับการอนุมาน (inference) ประสิทธิภาพสูงที่ออกแบบมาสำหรับโมเดลภาษาขนาดใหญ่ (LLMs) โดยมอบการให้บริการที่ปรับให้เหมาะสมด้วย continuous batching เพื่อให้ได้ปริมาณงานสูง และมี API ที่เข้ากันได้กับ OpenAI สำหรับการผสานรวมแอปพลิเคชันได้อย่างราบรื่น สิ่งนี้ทำให้ vLLM เหมาะอย่างยิ่งสำหรับการใช้งานจริง (production deployments) ที่ความเร็วและประสิทธิภาพของทรัพยากรเป็นสิ่งสำคัญ

คู่มือนี้จะสอนวิธีการให้บริการ LLM โดยใช้ vLLM แบบคอนเทนเนอร์บน iGPU และการโต้ตอบกับโมเดลผ่าน OpenAI Python API

## สิ่งที่คุณจะได้เรียนรู้

- วิธีการตั้งค่าและเริ่มต้นเซิร์ฟเวอร์ vLLM ด้วยการรองรับ AMD ROCm™
- วิธีการโต้ตอบกับโมเดลผ่านปลายทาง API ที่เข้ากันได้กับ OpenAI
- วิธีการส่งพรอมต์ไปยังเซิร์ฟเวอร์ภายในเครื่องด้วย `vllm-prompt`

## การติดตั้งซอฟต์แวร์ที่จำเป็น

vLLM ทำงานในคอนเทนเนอร์ที่สร้างไว้ล่วงหน้าพร้อม ROCm และ dependencies ที่จับคู่กันไว้ล่วงหน้า ไม่จำเป็นต้องติดตั้งเพิ่มเติม

ไม่มีขั้นตอนการติดตั้ง vLLM ฝั่งเครื่องโฮสต์ เริ่มต้น vLLM ด้วย:

```bash
vllm-launch
```

ตัวเรียกใช้งาน (launcher) จะเริ่มต้นคอนเทนเนอร์ กำหนดเป้าหมายไปที่ iGPU และเปิดใช้งานเซิร์ฟเวอร์ vLLM ที่เข้ากันได้กับ OpenAI ในเครื่องภายใน หรืออีกวิธีหนึ่งคือคลิกที่ไอคอน vLLM ในแถบงาน (taskbar)

## เริ่มต้นใช้งานอย่างรวดเร็ว

### 1. ยืนยันว่าเซิร์ฟเวอร์ vLLM กำลังทำงานอยู่

`vllm-launch` อาจใช้เวลาสองสามนาทีในการเริ่มต้นทุกอย่าง เมื่อเริ่มต้นแล้ว เซิร์ฟเวอร์จะพร้อมใช้งานที่ `http://localhost:8001` ให้เปิดเทอร์มินัลที่ใช้เรียกใช้งานไว้ เนื่องจากเซิร์ฟเวอร์ทำงานอยู่เบื้องหน้า (foreground) จากนั้นเปิดเทอร์มินัลแยกต่างหากสำหรับขั้นตอนที่เหลือ ตัวอย่างด้านล่างใช้ `Qwen/Qwen3-1.7B`; หากตัวเรียกใช้งานของคุณถูกกำหนดค่าให้ใช้โมเดลอื่น ให้แทนที่ด้วยรหัสโมเดล (model ID) นั้นในคำขอ

### 2. ส่งพรอมต์

ใช้สคริปต์ `vllm-prompt` ที่มีให้เพื่อส่งคำขอไปยังเซิร์ฟเวอร์ vLLM ที่เข้ากันได้กับ OpenAI ในเครื่องภายใน:

```bash
vllm-prompt "Tell me a story"
```

### 3. สนทนากับโมเดลโดยใช้ OpenAI Python API

เนื่องจาก vLLM เปิดเผย API ที่เข้ากันได้กับ OpenAI คุณสามารถใช้แพ็กเกจ Python `openai` เพื่อโต้ตอบกับมันได้

ก่อนอื่น ให้สร้างสภาพแวดล้อมเสมือน (virtual environment) ของ Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->
<!-- @os:end -->

ติดตั้งแพ็กเกจ OpenAI
```bash
pip install openai
```

สร้างไคลเอนต์ `OpenAI` ที่ชี้ไปยังเซิร์ฟเวอร์ vLLM ในเครื่องภายในแทนที่จะเป็นเซิร์ฟเวอร์ของ OpenAI `api_key` เป็นสิ่งจำเป็นสำหรับไคลเอนต์ แต่ vLLM ไม่ได้ตรวจสอบความถูกต้อง ดังนั้นสตริงใดก็ได้ก็ใช้งานได้:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

จากนั้น ส่งคำขอ chat completion ซึ่งใช้รูปแบบข้อความเดียวกันกับ OpenAI API — รายการข้อความที่มีบทบาท (roles) เช่น `"user"` และ `"assistant"` การตั้งค่า `stream=True` หมายความว่าคำตอบจะมาถึงแบบทยอย (incrementally) แทนที่จะมาพร้อมกันทั้งหมด:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

สุดท้าย ให้วนซ้ำ (iterate) ผ่านชิ้นส่วนข้อมูลที่สตรีมมาและพิมพ์แต่ละส่วนของข้อความทันทีที่มาถึง:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

สคริปต์ [chat_with_model.py](assets/chat_with_model.py) ที่มีให้นั้นมีตัวอย่างทั้งหมดและสามารถดาวน์โหลดได้


## การเลือกและกำหนดค่าโมเดล

โดยค่าเริ่มต้น `vllm-launch` ให้บริการ `Qwen/Qwen3-1.7B` เป็นโมเดลทดสอบที่พอร์ต `8001` คุณสามารถเปลี่ยนโมเดล พอร์ต และพารามิเตอร์การให้บริการของ vLLM ได้โดยไม่ต้องสร้างคอนเทนเนอร์ใหม่หรือแก้ไขคอนเทนเนอร์

### โมเดลที่ทดสอบโดย AMD

โมเดลต่อไปนี้ได้รับการกำหนดค่าไว้ล่วงหน้าและผ่านการตรวจสอบโดย AMD:

| โมเดล | หมายเหตุ |
|-------|-------|
| `Qwen/Qwen3-1.7B` | โมเดลเริ่มต้น มีขนาดเล็กและโหลดได้รวดเร็ว |
| `openai/gpt-oss-20b` | โมเดลขนาดใหญ่กว่าสำหรับคำตอบที่มีคุณภาพสูงกว่า |

### การเรียกใช้งานโมเดลอื่น

ระบุรหัสโมเดลด้วย `--model` (หรือ `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### การเปลี่ยนพอร์ต

ระบุพอร์ตที่สูงกว่า 1024 ด้วย `--port` (หรือ `-p`); ค่าเริ่มต้นคือ `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

หากคุณเปลี่ยนพอร์ต ให้ชี้ `base_url` ของไคลเอนต์ของคุณไปยังพอร์ตเดียวกัน (ตัวอย่างเช่น `http://localhost:8080/v1`)

### การส่งพารามิเตอร์ vLLM เพิ่มเติม

อาร์กิวเมนต์เพิ่มเติมใดๆ จะถูกส่งต่อไปยัง vLLM โดยตรง ดังนั้นคุณสามารถปรับแต่งพฤติกรรมการให้บริการ เช่น ความยาวของบริบท (context length) หรือชนิดข้อมูล (data type) มีสองวิธีในการระบุค่าเหล่านี้

**แบบอินไลน์ (Inline)** หลังจากตัวเลือกของตัวเรียกใช้งาน:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**แบบถาวร (Persistently)** ในไฟล์การกำหนดค่าที่ `~/.local/share/vLLM/vllm-launch.conf` ไฟล์นี้ไม่มีอยู่โดยค่าเริ่มต้น — ให้สร้างไฟล์ขึ้นมาและเพิ่มอาร์กิวเมนต์ของคุณเป็นอาร์เรย์ (array) ของ Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

ใช้ `+=` เพื่อเพิ่มต่อท้ายอาร์กิวเมนต์เริ่มต้นแทนที่จะแทนที่ค่าเดิม:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

หากต้องการดูตัวเลือกทั้งหมดของตัวเรียกใช้งานได้ทุกเมื่อ ให้รัน:

```bash
vllm-launch --help
```

### ตำแหน่งที่จัดเก็บโมเดล

`vllm-launch` จะค้นหาโมเดลในสองตำแหน่ง:

| ตำแหน่ง | เส้นทาง |
|----------|------|
| โมเดลระดับระบบ | `/var/cache/models` |
| โมเดลของผู้ใช้ | `~/.local/share/vLLM/models` |

คุณสามารถวางโมเดลที่ดาวน์โหลดมาไว้ในไดเรกทอรีใดไดเรกทอรีหนึ่งและเรียกใช้งานได้โดยการระบุเส้นทางหรือรหัสของโมเดลไปยัง `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **หมายเหตุ**: การรันโมเดลที่คุณดาวน์โหลดเองด้วยวิธีนี้คาดว่าจะทำงานได้เมื่อโมเดลถูกวางไว้ในไดเรกทอรีใดไดเรกทอรีหนึ่งด้านบน แต่ขั้นตอนการทำงานนี้ยังไม่ได้รับการตรวจสอบอย่างเป็นทางการจาก AMD

## สรุป

ในคู่มือนี้ คุณได้เรียนรู้วิธีการ:

- เริ่มต้น vLLM แบบคอนเทนเนอร์พร้อมการรองรับ ROCm บน iGPU
- เริ่มต้นเซิร์ฟเวอร์ vLLM ด้วยปลายทาง API ที่เข้ากันได้กับ OpenAI บนพอร์ต 8001
- ส่งพรอมต์ด้วย `vllm-prompt`
- เรียก API ไปยังเซิร์ฟเวอร์ vLLM โดยใช้ทั้งคำขอแบบสตรีมมิงและแบบไม่สตรีมมิง
- แก้ไขปัญหาทั่วไปเกี่ยวกับการเริ่มต้นเซิร์ฟเวอร์ หน่วยความจำ และการเชื่อมต่อของไคลเอนต์

ตอนนี้คุณมีการติดตั้งใช้งาน vLLM แบบคอนเทนเนอร์สำหรับให้บริการโมเดลภาษาขนาดใหญ่ด้วยประสิทธิภาพที่ปรับให้เหมาะสมบน iGPU แล้ว

## ขั้นตอนถัดไป

- **ลองใช้โมเดลที่แตกต่างกัน** — ใช้ `vllm-launch --model <model>` เพื่อทดลองใช้ LLM ที่แตกต่างกันและเปรียบเทียบประสิทธิภาพ (ดู [การเลือกและกำหนดค่าโมเดล](#choosing-and-configuring-a-model))
- **สร้างแอปพลิเคชัน** — ใช้ API ที่เข้ากันได้กับ OpenAI เพื่อผสานรวม vLLM เข้ากับแอป Python, แชทบอท หรือเวิร์กโฟลว์การทำงานอัตโนมัติ
- **ปรับแต่งและให้บริการ (Fine-tune and serve)** — ปรับแต่งโมเดลโดยใช้ LoRA หรือ QLoRA จากนั้นนำไปใช้งานด้วย vLLM เพื่อการอนุมานที่ปรับให้เหมาะสม
