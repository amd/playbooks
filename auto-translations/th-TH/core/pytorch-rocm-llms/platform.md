# การกำหนดค่าแพลตฟอร์ม

เอกสารนี้อธิบายการกำหนดค่าแพลตฟอร์มที่คาดหวังสำหรับการรัน playbook นี้

## ข้อกำหนดเบื้องต้น

PyTorch ที่รองรับ ROCm ได้รับการติดตั้งไว้ล่วงหน้าบน AMD Ryzen™ AI Halo Developer Platform สำหรับอุปกรณ์อื่นๆ ทั้งหมด ผู้ใช้ต้องติดตั้ง PyTorch ที่รองรับ ROCm ด้วยตนเอง โปรดดูส่วนที่เกี่ยวข้องสำหรับระบบปฏิบัติการของคุณ:

### Windows

| Component     | Version         | Notes                             |
|---------------|-----------------|-----------------------------------|
| **PyTorch**   | 2.9 หรือใหม่กว่า    | ติดตั้งไว้ล่วงหน้าบน AMD Ryzen AI Halo Developer Platform; ต้องติดตั้งด้วยตนเองบนอุปกรณ์อื่นๆ ทั้งหมด |

### Linux

| Component     | Version         | Notes                             |
|---------------|-----------------|-----------------------------------|
| **PyTorch**   | 2.9 หรือใหม่กว่า    | ติดตั้งไว้ล่วงหน้าบน AMD Ryzen AI Halo Developer Platform; ต้องติดตั้งด้วยตนเองบนอุปกรณ์อื่นๆ ทั้งหมด |

## โมเดลที่จำเป็น

โมเดลต่อไปนี้ได้รับการทดสอบและปรับให้เหมาะสมสำหรับแพลตฟอร์มของคุณ:

| Model | Parameters | Size | Download Location |
|-------|------------|------|-------------------|
| **openai/gpt-oss-20b** | 20B | ~40GB | ติดตั้งไว้ล่วงหน้าบน AMD Ryzen AI Halo Developer Platform; ต้องติดตั้งด้วยตนเองบนอุปกรณ์อื่นๆ ทั้งหมด |

โมเดลจะถูกดาวน์โหลดโดยอัตโนมัติไปยังไดเรกทอรีแคชของ Hugging Face:
- **Windows**: `C:\Users\<username>\.cache\huggingface\hub\`
- **Linux**: `~/.cache/huggingface/hub/`

ตรวจสอบให้แน่ใจว่ามีพื้นที่ว่างอย่างน้อย **50GB** สำหรับการจัดเก็บโมเดล

## ข้อกำหนดด้านเครือข่าย

การตั้งค่าครั้งแรกต้องการการเข้าถึงอินเทอร์เน็ตเพื่อดาวน์โหลดโมเดลจาก Hugging Face หลังจากดาวน์โหลดแล้ว playbook สามารถรันแบบออฟไลน์ได้

- การดาวน์โหลดโมเดลครั้งแรกอาจใช้เวลา **5-10 นาที** ขึ้นอยู่กับขนาดโมเดลและความเร็วการเชื่อมต่อ
- โมเดลจะถูกแคชไว้ในเครื่องและไม่จำเป็นต้องดาวน์โหลดซ้ำ
