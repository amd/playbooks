### n8n

<!-- @os:windows -->

1. เปิด PowerShell หรือ Command Prompt
2. ติดตั้ง n8n แบบ global โดยใช้ npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

ติดตั้ง n8n แบบ global โดยใช้ npm:
```bash
npm install -g n8n
```

> **หมายเหตุ**: ดู [n8n Documentation](https://docs.n8n.io/hosting/installation/npm/) สำหรับตัวเลือกการติดตั้งเพิ่มเติม

<!-- @os:end -->
