### n8n

<!-- @os:windows -->

1. Deschideți PowerShell sau Command Prompt
2. Instalați n8n global folosind npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Instalați n8n global folosind npm:
```bash
npm install -g n8n
```

> **Notă**: Consultați [Documentația n8n](https://docs.n8n.io/hosting/installation/npm/) pentru mai multe opțiuni de instalare.

<!-- @os:end -->
