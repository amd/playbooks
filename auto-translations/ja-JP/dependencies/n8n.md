### n8n

<!-- @os:windows -->

1. PowerShell またはコマンドプロンプトを開く
2. npm を使用して n8n をグローバルにインストールする:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

npm を使用して n8n をグローバルにインストールする:
```bash
npm install -g n8n
```

> **注意**: その他のインストールオプションについては、[n8n ドキュメント](https://docs.n8n.io/hosting/installation/npm/)を参照してください。

<!-- @os:end -->
