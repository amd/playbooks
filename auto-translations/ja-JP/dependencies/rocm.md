#### ROCm

**現在のユーザーをrenderおよびvideoグループに追加します。** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**設定を適用するためにシステムを再起動します。**
```bash
sudo reboot
```

**作成した仮想環境にROCmをインストールします。**
> **注**: 続行する前に仮想環境が有効になっていることを確認してください。
