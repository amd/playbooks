#### ROCm

**現在のユーザーを render グループと video グループに追加します。** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**設定を適用するためにシステムを再起動します。**
```bash
sudo reboot
```

**作成した仮想環境に ROCm をインストールします。**
> **注**: 続行する前に、仮想環境が有効になっていることを確認してください。
