#### ROCm

**将当前用户添加到 render 和 video 组。** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**重启系统以使设置生效。**
```bash
sudo reboot
```

**在创建的虚拟环境中安装 ROCm。**
> **注意**：请确保在继续之前虚拟环境已激活。
