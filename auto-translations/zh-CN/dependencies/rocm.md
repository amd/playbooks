#### ROCm

**将当前用户添加到 render 和 video 组。** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**重启系统以应用设置。**
```bash
sudo reboot
```

**在已创建的虚拟环境中安装 ROCm。**
> **注意**：在继续操作之前，请确保虚拟环境已激活。
