### n8n

<!-- @os:windows -->

1. 打开 PowerShell 或命令提示符
2. 使用 npm 全局安装 n8n：
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

使用 npm 全局安装 n8n：
```bash
npm install -g n8n
```

> **注意**：请参阅 [n8n 文档](https://docs.n8n.io/hosting/installation/npm/) 了解更多安装选项。

<!-- @os:end -->
