### n8n

<!-- @os:windows -->

1. 打开 PowerShell 或命令提示符
2. 使用 npm 全局安装 n8n:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

使用 npm 全局安装 n8n:
```bash
npm install -g n8n
```

> **注意**：更多安装选项请参见 [n8n Documentation](https://docs.n8n.io/hosting/installation/npm/)。

<!-- @os:end -->
