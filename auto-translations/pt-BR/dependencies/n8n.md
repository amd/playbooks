### n8n

<!-- @os:windows -->

1. Abra o PowerShell ou o Prompt de Comando
2. Instale o n8n globalmente usando o npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Instale o n8n globalmente usando o npm:
```bash
npm install -g n8n
```

> **Observação**: Consulte a [Documentação do n8n](https://docs.n8n.io/hosting/installation/npm/) para mais opções de instalação.

<!-- @os:end -->
