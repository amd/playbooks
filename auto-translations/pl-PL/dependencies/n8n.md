### n8n

<!-- @os:windows -->

1. Otwórz PowerShell lub wiersz polecenia
2. Zainstaluj n8n globalnie przy użyciu npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Zainstaluj n8n globalnie przy użyciu npm:
```bash
npm install -g n8n
```

> **Uwaga**: Zobacz [dokumentację n8n](https://docs.n8n.io/hosting/installation/npm/), aby poznać więcej opcji instalacji.

<!-- @os:end -->
