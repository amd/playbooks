### n8n

<!-- @os:windows -->

1. افتح PowerShell أو موجه الأوامر
2. ثبّت n8n بشكل عام باستخدام npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

ثبّت n8n بشكل عام باستخدام npm:
```bash
npm install -g n8n
```

> **ملاحظة**: راجع [توثيق n8n](https://docs.n8n.io/hosting/installation/npm/) لمزيد من خيارات التثبيت.

<!-- @os:end -->
