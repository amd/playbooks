# تكوين المنصة

يصف هذا المستند تكوينات المنصة المتوقعة لتشغيل هذا الدليل التشغيلي.

## التطبيقات/الأطر المطلوبة

### Windows/Linux

يجب تثبيت GAIA مسبقًا باتباع التعليمات الواردة في [دليل تثبيت GAIA](../../dependencies/gaia.md).

يجب تثبيت Lemonade Server مسبقًا باتباع التعليمات الواردة في [دليل تثبيت Lemonade](../../dependencies/lemonade.md).

## النماذج المطلوبة

### Windows/Linux

يستخدم وكيل المستشار للأجهزة **Qwen3-Coder-30B** للاستدلال الخاص بالوكيل. يتم تنزيل هذا النموذج تلقائيًا أثناء تشغيل `gaia init`. لا يلزم تنزيل أي نماذج يدويًا.
