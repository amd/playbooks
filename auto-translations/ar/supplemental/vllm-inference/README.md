## نظرة عامة

vLLM هو محرك استدلال عالي الأداء مصمم لنماذج اللغة الكبيرة (LLMs). يوفر خدمة محسّنة مع تجميع دفعات مستمر (continuous batching) لتحقيق إنتاجية عالية، وواجهة برمجة تطبيقات متوافقة مع OpenAI للتكامل السلس مع التطبيقات. هذا ما يجعل vLLM ممتازًا لعمليات النشر الإنتاجية حيث تكون السرعة وكفاءة الموارد أمرًا بالغ الأهمية.

يعلّمك هذا الدليل الإرشادي كيفية خدمة نماذج LLM باستخدام vLLM المُحوسط (containerized) على وحدة معالجة الرسومات المدمجة (iGPU) والتفاعل مع النماذج من خلال واجهة برمجة تطبيقات OpenAI بلغة Python.

## ما ستتعلمه

- كيفية إعداد وتشغيل خادم vLLM مع دعم AMD ROCm™
- كيفية التفاعل مع النماذج عبر نقاط نهاية API متوافقة مع OpenAI
- كيفية إرسال الطلبات (prompts) إلى الخادم المحلي باستخدام `vllm-prompt`

## تثبيت متطلبات البرامج المسبقة

يعمل vLLM ضمن حاوية جاهزة مسبقًا مع ROCm واعتمادياته المطابقة مسبقًا. لا يلزم أي تثبيت إضافي.

لا توجد خطوة تثبيت لـ vLLM على الجهاز المضيف. ابدأ تشغيل vLLM باستخدام:

```bash
vllm-launch
```

يقوم المُشغّل (launcher) بتشغيل الحاوية، واستهداف وحدة معالجة الرسومات المدمجة، وكشف خادم vLLM محلي متوافق مع OpenAI. بدلًا من ذلك، انقر على أيقونة vLLM في شريط المهام.

## البدء السريع

### 1. تأكد من أن خادم vLLM قيد التشغيل

قد يستغرق `vllm-launch` بضع دقائق لتهيئة كل شيء. بمجرد بدء التشغيل، يصبح الخادم متاحًا على العنوان `http://localhost:8001`. اترك طرفية التشغيل مفتوحة لأن الخادم يعمل في المقدمة (foreground)، ثم افتح طرفية منفصلة لبقية الخطوات. تستخدم الأمثلة أدناه `Qwen/Qwen3-1.7B`؛ إذا كان المُشغّل الخاص بك مُهيّأً لنموذج مختلف، استبدل معرّف ذلك النموذج في الطلبات.

### 2. إرسال طلب (prompt)

استخدم النص البرمجي `vllm-prompt` المُقدَّم لإرسال طلب إلى خادم vLLM المحلي المتوافق مع OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. التحدث مع النموذج باستخدام واجهة برمجة تطبيقات OpenAI بلغة Python

نظرًا لأن vLLM يكشف واجهة برمجة تطبيقات متوافقة مع OpenAI، يمكنك استخدام حزمة `openai` الخاصة بـ Python للتفاعل معه.

أولًا، أنشئ بيئة افتراضية لـ Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

قم بتثبيت حزمة OpenAI
```bash
pip install openai
```

أنشئ عميل `OpenAI` موجّهًا إلى خادم vLLM المحلي بدلًا من خوادم OpenAI. مفتاح `api_key` مطلوب من قِبل العميل، لكن vLLM لا يتحقق من صحته، لذا تصلح أي سلسلة نصية:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

بعد ذلك، أرسل طلب إكمال محادثة (chat completion). يستخدم هذا نفس تنسيق الرسائل الخاص بواجهة برمجة تطبيقات OpenAI — قائمة من الرسائل بأدوار مثل `"user"` و`"assistant"`. يعني ضبط `stream=True` أن الاستجابة ستصل بشكل تدريجي بدلًا من دفعة واحدة:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

أخيرًا، مرّ عبر الأجزاء المتدفقة (streamed chunks) واطبع كل جزء من النص فور وصوله:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

يحتوي النص البرمجي المُرفق [chat_with_model.py](assets/chat_with_model.py) على المثال الكامل ويمكن تنزيله.


## اختيار وضبط نموذج

بشكل افتراضي، يقدّم `vllm-launch` النموذج `Qwen/Qwen3-1.7B` كنموذج اختباري على المنفذ `8001`. يمكنك تغيير النموذج، والمنفذ، ومعاملات خدمة vLLM دون إعادة بناء الحاوية أو تعديلها.

### النماذج التي اختبرتها AMD

النماذج التالية مُهيَّأة مسبقًا ومُتحقَّق منها من قِبل AMD:

| النموذج | ملاحظات |
|-------|-------|
| `Qwen/Qwen3-1.7B` | النموذج الافتراضي. خفيف الوزن وسريع التحميل. |
| `openai/gpt-oss-20b` | نموذج أكبر لاستجابات ذات جودة أعلى. |

### تشغيل نموذج مختلف

مرّر معرّف النموذج باستخدام `--model` (أو `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### تغيير المنفذ

مرّر منفذًا أعلى من 1024 باستخدام `--port` (أو `-p`)؛ المنفذ الافتراضي هو `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

إذا غيّرت المنفذ، وجّه `base_url` الخاص بالعميل إلى نفس المنفذ (على سبيل المثال `http://localhost:8080/v1`).

### تمرير معاملات إضافية لـ vLLM

يتم توجيه أي معاملات إضافية مباشرة إلى vLLM، بحيث يمكنك ضبط سلوك الخدمة مثل طول السياق أو نوع البيانات. هناك طريقتان لتوفيرها.

**بشكل مضمّن (Inline)**، بعد خيارات المُشغّل:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**بشكل دائم**، في ملف إعدادات على المسار `~/.local/share/vLLM/vllm-launch.conf`. لا يوجد هذا الملف افتراضيًا — أنشئه وأضف معاملاتك كمصفوفة Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

استخدم `+=` لإلحاق المعاملات بالمعاملات الافتراضية بدلًا من استبدالها:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

لعرض جميع خيارات المُشغّل في أي وقت، شغّل:

```bash
vllm-launch --help
```

### أين تُخزَّن النماذج

يبحث `vllm-launch` عن النماذج في موقعين:

| الموقع | المسار |
|----------|------|
| نماذج النظام | `/var/cache/models` |
| نماذج المستخدم | `~/.local/share/vLLM/models` |

يمكنك وضع نموذج تم تنزيله في أي من الدليلين وتشغيله بتمرير مساره أو معرّفه إلى `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **ملاحظة**: يُتوقع أن يعمل تشغيل نموذجك الخاص الذي قمت بتنزيله بهذه الطريقة بمجرد وضع النموذج في أحد الدليلين أعلاه، ولكن لم يتم التحقق رسميًا من هذا التدفق بعد من قِبل AMD.

## الملخص

في هذا الدليل الإرشادي، تعلمت كيفية:

- تشغيل vLLM المُحوسط (containerized) مع دعم ROCm على وحدة معالجة الرسومات المدمجة
- تشغيل خادم vLLM بنقاط نهاية API متوافقة مع OpenAI على المنفذ 8001
- إرسال الطلبات (prompts) باستخدام `vllm-prompt`
- إجراء استدعاءات API إلى خادم vLLM باستخدام طلبات متدفقة (streaming) وغير متدفقة على حد سواء
- استكشاف المشكلات الشائعة وإصلاحها المتعلقة ببدء تشغيل الخادم، والذاكرة، واتصالات العميل

أصبح لديك الآن نشر vLLM مُحوسط لخدمة نماذج اللغة الكبيرة بأداء محسّن على وحدة معالجة الرسومات المدمجة.

## الخطوات التالية

- **جرّب نماذج مختلفة** — استخدم `vllm-launch --model <model>` لتجربة نماذج LLM مختلفة ومقارنة الأداء (راجع [اختيار وضبط نموذج](#choosing-and-configuring-a-model)).
- **ابنِ تطبيقًا** — استخدم واجهة برمجة التطبيقات المتوافقة مع OpenAI لدمج vLLM في تطبيق Python، أو روبوت محادثة، أو سير عمل آلي.
- **الضبط الدقيق والخدمة** — قم بالضبط الدقيق لنموذج باستخدام LoRA أو QLoRA، ثم انشره باستخدام vLLM للحصول على استدلال محسّن.
