## نظرة عامة

vLLM هو محرك استدلال عالي الأداء مصمم لنماذج اللغة الكبيرة (LLMs). يوفر خدمة محسّنة مع تجميع دفعات مستمر (continuous batching) لتحقيق إنتاجية عالية وواجهة برمجة تطبيقات متوافقة مع OpenAI للتكامل السلس مع التطبيقات. هذا ما يجعل vLLM مناسبًا لعمليات النشر الإنتاجية حيث تكون السرعة وكفاءة استخدام الموارد أمرًا بالغ الأهمية.

يعلّمك هذا الدليل الإرشادي كيفية تقديم خدمة نماذج اللغة الكبيرة باستخدام vLLM المُحتوى (containerized) على وحدة معالجة الرسومات المدمجة (integrated GPU) والتفاعل مع النماذج من خلال واجهة برمجة تطبيقات OpenAI بلغة Python.

## ما ستتعلمه

- كيفية إعداد وتشغيل خادم vLLM مع دعم AMD ROCm™
- كيفية التفاعل مع النماذج عبر نقاط نهاية واجهة برمجة تطبيقات متوافقة مع OpenAI
- كيفية إرسال المطالبات (prompts) إلى الخادم المحلي باستخدام `vllm-prompt`

## تثبيت المتطلبات البرمجية الأساسية

يستخدم هذا الدليل الإرشادي صورة حاوية (container image) مُعدّة مسبقًا تتضمن vLLM ودعم ROCm والبرامج النصية المساعدة اللازمة لتشغيل الخادم. لست بحاجة إلى تثبيت PyTorch أو vLLM أو البرامج النصية المحلية للدليل الإرشادي يدويًا.

لا توجد خطوة تثبيت لـ vLLM على جهاز المضيف. ابدأ تشغيل vLLM باستخدام:

```bash
vllm-launch
```

يقوم المُشغّل (launcher) بتشغيل الحاوية، واستهداف وحدة معالجة الرسومات المدمجة، وإتاحة خادم vLLM محلي متوافق مع OpenAI. بدلاً من ذلك، انقر على أيقونة vLLM في شريط المهام.

## البدء السريع

### 1. التأكد من تشغيل خادم vLLM

قد يستغرق تشغيل `vllm-launch` بضع دقائق لتهيئة كل شيء. بمجرد بدء تشغيله، يصبح الخادم متاحًا على `http://localhost:8001`. أبقِ نافذة الطرفية (terminal) الخاصة بالتشغيل مفتوحة لأن الخادم يعمل في المقدمة (foreground)، ثم افتح نافذة طرفية منفصلة لبقية الخطوات. تستخدم الأمثلة أدناه `Qwen/Qwen3-1.7B`؛ إذا كان المُشغّل الخاص بك مُهيأً لنموذج مختلف، فاستبدل معرّف ذلك النموذج في الطلبات.

### 2. إرسال مطالبة (Prompt)

استخدم البرنامج النصي `vllm-prompt` المتوفر لإرسال طلب إلى خادم vLLM المحلي المتوافق مع OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. الدردشة مع النموذج باستخدام واجهة برمجة تطبيقات OpenAI بلغة Python

نظرًا لأن vLLM يوفر واجهة برمجة تطبيقات متوافقة مع OpenAI، يمكنك استخدام حزمة `openai` الخاصة بلغة Python للتفاعل معها.

أولاً، أنشئ بيئة افتراضية (virtual environment) خاصة بلغة Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

ثبّت حزمة OpenAI
```bash
pip install openai
```

أنشئ عميل `OpenAI` موجّهًا نحو خادم vLLM المحلي بدلاً من خوادم OpenAI. مفتاح `api_key` مطلوب من قبل العميل لكن vLLM لا يتحقق من صحته، لذا يمكن استخدام أي سلسلة نصية:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

بعد ذلك، أرسل طلب إكمال دردشة (chat completion). يستخدم هذا نفس تنسيق الرسائل الخاص بواجهة برمجة تطبيقات OpenAI — قائمة من الرسائل مع أدوار مثل `"user"` و`"assistant"`. يعني ضبط `stream=True` أن الاستجابة ستصل تدريجيًا بدلاً من دفعة واحدة:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

أخيرًا، كرّر المرور عبر القطع المُبثّة (streamed chunks) واطبع كل جزء من النص عند وصوله:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

يحتوي البرنامج النصي المرفق [chat_with_model.py](assets/chat_with_model.py) على المثال الكامل ويمكن تنزيله.

## الملخص

في هذا الدليل الإرشادي، تعلمت كيفية:

- تشغيل vLLM المُحتوى مع دعم ROCm على وحدة معالجة الرسومات المدمجة
- تشغيل خادم vLLM مع نقاط نهاية واجهة برمجة تطبيقات متوافقة مع OpenAI على المنفذ 8001
- إرسال المطالبات باستخدام `vllm-prompt`
- إجراء استدعاءات واجهة برمجة التطبيقات إلى خادم vLLM باستخدام كل من طلبات البث والطلبات غير المُبثّة
- استكشاف المشكلات الشائعة وإصلاحها المتعلقة ببدء تشغيل الخادم والذاكرة واتصالات العميل

أصبح لديك الآن نشر vLLM مُحتوى لتقديم خدمة نماذج اللغة الكبيرة بأداء محسّن على وحدة معالجة الرسومات المدمجة.

## الخطوات التالية

- **جرّب نماذج مختلفة** — استبدل النموذج في تهيئة `vllm-launch` لتجربة نماذج لغة كبيرة مختلفة ومقارنة الأداء.
- **بناء تطبيق** — استخدم واجهة برمجة التطبيقات المتوافقة مع OpenAI لدمج vLLM في تطبيق Python أو روبوت دردشة أو سير عمل آلي.
- **الضبط الدقيق والتقديم** — قم بالضبط الدقيق (fine-tune) لنموذج باستخدام LoRA أو QLoRA، ثم انشره باستخدام vLLM للاستدلال المحسّن.
