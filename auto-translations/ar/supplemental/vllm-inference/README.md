## نظرة عامة

vLLM هو محرك استدلال عالي الأداء مصمم للنماذج اللغوية الكبيرة (LLMs). يوفر خدمةً محسّنة مع المعالجة الدفعية المستمرة لتحقيق إنتاجية عالية، وواجهة برمجية متوافقة مع OpenAI لتكامل سلس مع التطبيقات. يجعل هذا vLLM خياراً ممتازاً للنشر في بيئات الإنتاج حيث تكون السرعة وكفاءة الموارد أموراً بالغة الأهمية.

يعلّمك هذا الدليل التطبيقي كيفية تقديم النماذج اللغوية الكبيرة باستخدام vLLM في حاوية على GPU المدمجة، والتفاعل مع النماذج عبر واجهة برمجة Python المتوافقة مع OpenAI.

## ما ستتعلمه

- كيفية إعداد وتشغيل خادم vLLM مع دعم AMD ROCm™
- كيفية التفاعل مع النماذج عبر نقاط نهاية الواجهة البرمجية المتوافقة مع OpenAI
- كيفية إرسال المطالبات إلى الخادم المحلي باستخدام `vllm-prompt`

## تثبيت المتطلبات الأساسية للبرامج

يستخدم هذا الدليل التطبيقي صورة حاوية مُعدّة مسبقاً تتضمن vLLM ودعم ROCm والسكريبتات المساعدة اللازمة لتشغيل الخادم. لا تحتاج إلى تثبيت PyTorch أو vLLM أو سكريبتات الدليل التطبيقي المحلية يدوياً.

لا توجد خطوة تثبيت لـ vLLM على المضيف. ابدأ تشغيل vLLM بـ:

```bash
vllm-launch
```

يبدأ المُشغِّل الحاوية، ويستهدف GPU المدمجة، ويعرض خادم vLLM محلياً متوافقاً مع OpenAI. بدلاً من ذلك، انقر على أيقونة vLLM في شريط المهام.

## البدء السريع

### 1. التأكد من تشغيل خادم vLLM

قد يستغرق `vllm-launch` بضع دقائق لتهيئة كل شيء. بمجرد بدء التشغيل، يكون الخادم متاحاً على `http://localhost:8001`. احتفظ بنافذة الطرفية المُشغِّلة مفتوحة لأن الخادم يعمل في المقدمة، ثم افتح نافذة طرفية منفصلة للخطوات المتبقية. تستخدم الأمثلة أدناه `Qwen/Qwen3-1.7B`؛ إذا كان مُشغِّلك مُهيَّأً لنموذج مختلف، فاستبدل معرّف ذلك النموذج في الطلبات.

### 2. إرسال مطالبة

استخدم سكريبت `vllm-prompt` المُرفق لإرسال طلب إلى خادم vLLM المحلي المتوافق مع OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. الدردشة مع النموذج باستخدام واجهة برمجة Python الخاصة بـ OpenAI

بما أن vLLM يعرض واجهة برمجية متوافقة مع OpenAI، يمكنك استخدام حزمة Python `openai` للتفاعل معه.

أولاً، أنشئ بيئة Python افتراضية:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

ثبّت حزمة OpenAI
```bash
pip install openai
```

أنشئ عميل `OpenAI` يشير إلى خادم vLLM المحلي بدلاً من خوادم OpenAI. يُطلب `api_key` من قِبَل العميل لكن vLLM لا يتحقق منه، لذا يصلح أي نص:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

ثم أرسل طلب إكمال محادثة. يستخدم هذا نفس تنسيق الرسائل الخاص بواجهة برمجة OpenAI — قائمة من الرسائل بأدوار مثل `"user"` و`"assistant"`. يعني ضبط `stream=True` أن الاستجابة ستصل بشكل تدريجي بدلاً من وصولها دفعةً واحدة:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

أخيراً، كرّر على الأجزاء المتدفقة واطبع كل قطعة نصية فور وصولها:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

يحتوي سكريبت [chat_with_model.py](assets/chat_with_model.py) المُرفق على المثال الكامل ويمكن تنزيله.

## الملخص

في هذا الدليل التطبيقي، تعلّمت كيفية:

- تشغيل vLLM في حاوية مع دعم ROCm على GPU المدمجة
- تشغيل خادم vLLM مع نقاط نهاية واجهة برمجية متوافقة مع OpenAI على المنفذ 8001
- إرسال المطالبات باستخدام `vllm-prompt`
- إجراء استدعاءات واجهة برمجية إلى خادم vLLM باستخدام طلبات البث وغير البث
- استكشاف المشكلات الشائعة المتعلقة ببدء تشغيل الخادم والذاكرة واتصالات العميل

أصبح لديك الآن نشر vLLM في حاوية لتقديم النماذج اللغوية الكبيرة بأداء محسّن على GPU المدمجة.

## الخطوات التالية

- **جرّب نماذج مختلفة** — استبدل النموذج في إعدادات `vllm-launch` لتجربة نماذج LLM مختلفة ومقارنة الأداء.
- **ابنِ تطبيقاً** — استخدم الواجهة البرمجية المتوافقة مع OpenAI لدمج vLLM في تطبيق Python أو روبوت محادثة أو سير عمل آلي.
- **ضبط دقيق وتقديم** — اضبط نموذجاً بدقة باستخدام LoRA أو QLoRA، ثم انشره مع vLLM للاستدلال المحسّن.
