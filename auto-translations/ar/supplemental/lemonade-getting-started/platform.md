# تهيئة المنصة — Lemonade Local AI

يصف هذا المستند البرمجيات المثبتة مسبقًا، ومسارات النماذج، والمتطلبات الأساسية الخاصة بالمنصة والتي يفترضها هذا الدليل التوجيهي.

## البرمجيات المثبتة مسبقًا

| البرنامج | الإصدار | الغرض |
|----------|---------|-------|
| Lemonade Server | أحدث إصدار | خادم LLM محلي مزوّد بواجهة برمجة تطبيقات متوافقة مع OpenAI |
| Python | 3.10–3.13 | مطلوب لمثال عميل OpenAI Python |

## مسار تخزين النماذج الافتراضي

يتم تخزين النماذج التي يتم تنزيلها عبر Lemonade باستخدام مواصفة Hugging Face Hub:

| المنصة | المسار الافتراضي |
|--------|-------------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

لتغيير موقع التخزين، قم بتعيين متغير البيئة `HF_HOME`.

## متطلبات الأجهزة

| الجهاز المستهدف | المتطلبات |
|------------------|-----------|
| **CPU** | أي معالج x86-64 حديث (AMD أو Intel) |
| **GPU (Vulkan)** | أي GPU يدعم برنامج تشغيل Vulkan |
| **GPU (ROCm)** | سلسلة AMD Radeon RX 7000/9000 أو سلسلة Radeon PRO W7000؛ AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | معالج AMD Ryzen AI 300 series، Windows 11 |
