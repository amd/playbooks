# تكوين المنصة — Lemonade Local AI

يصف هذا المستند البرامج المثبتة مسبقاً، ومسارات النماذج، والمتطلبات الأساسية الخاصة بالمنصة التي يفترضها هذا الدليل.

## البرامج المثبتة مسبقاً

| البرنامج | الإصدار | الغرض |
|----------|---------|---------|
| Lemonade Server | أحدث إصدار | خادم LLM محلي مع واجهة برمجية متوافقة مع OpenAI |
| Python | 3.10–3.13 | مطلوب لمثال عميل OpenAI Python |

## مسار تخزين النماذج الافتراضي

يتم تخزين النماذج التي يتم تنزيلها عبر Lemonade وفق مواصفات Hugging Face Hub:

| المنصة | المسار الافتراضي |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

لتغيير موقع التخزين، قم بتعيين متغير البيئة `HF_HOME`.

## متطلبات الأجهزة

| الهدف | المتطلبات |
|----------------|-------------|
| **CPU** | أي معالج x86-64 حديث (AMD أو Intel) |
| **GPU (Vulkan)** | أي GPU يدعم تشغيل Vulkan |
| **GPU (ROCm)** | AMD Radeon RX 7000/9000 series أو Radeon PRO W7000 series؛ AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | معالج AMD Ryzen AI 300 series، Windows 11 |

## متطلبات الشبكة

- يلزم توفر اتصال بالإنترنت لتنزيل النموذج في المرة الأولى (من 1 إلى 25 جيجابايت حسب النموذج)
- لا يلزم توفر اتصال بالإنترنت بعد تنزيل النماذج
