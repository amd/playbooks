## Обзор

vLLM — это высокопроизводительный движок вывода, разработанный для больших языковых моделей (LLM). Он обеспечивает оптимизированное обслуживание с непрерывной пакетной обработкой (continuous batching) для высокой пропускной способности и API, совместимый с OpenAI, для бесшовной интеграции с приложениями. Это делает vLLM отличным выбором для промышленного развёртывания, где критически важны скорость и эффективность использования ресурсов.

Это руководство научит вас обслуживать LLM с помощью контейнеризированного vLLM на встроенном GPU и взаимодействовать с моделями через OpenAI Python API.

## Чему вы научитесь

- Как настроить и запустить сервер vLLM с поддержкой AMD ROCm™
- Как взаимодействовать с моделями через конечные точки API, совместимые с OpenAI
- Как отправлять запросы на локальный сервер с помощью `vllm-prompt`

## Установка необходимого программного обеспечения

В этом руководстве используется предварительно собранный образ контейнера, который включает vLLM, поддержку ROCm и вспомогательные скрипты, необходимые для запуска сервера. Вам не нужно устанавливать PyTorch, vLLM или локальные скрипты руководства вручную.

Установка vLLM на хосте не требуется. Запустите vLLM с помощью:

```bash
vllm-launch
```

Программа запуска запускает контейнер, нацеливается на встроенный GPU и предоставляет локальный сервер vLLM, совместимый с OpenAI. Также можно нажать на значок vLLM на панели задач.

## Быстрый старт

### 1. Убедитесь, что сервер vLLM запущен

`vllm-launch` может занять пару минут на инициализацию всего необходимого. После запуска сервер становится доступен по адресу `http://localhost:8001`. Держите терминал запуска открытым, так как сервер работает в переднем плане, затем откройте отдельный терминал для оставшихся шагов. В примерах ниже используется `Qwen/Qwen3-1.7B`; если ваша программа запуска настроена на другую модель, замените этот идентификатор модели в запросах.

### 2. Отправьте запрос

Используйте предоставленный скрипт `vllm-prompt` для отправки запроса на локальный сервер vLLM, совместимый с OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Общение с моделью с помощью OpenAI Python API

Поскольку vLLM предоставляет API, совместимый с OpenAI, вы можете использовать пакет Python `openai` для взаимодействия с ним.

Сначала создайте виртуальное окружение Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Установите пакет OpenAI
```bash
pip install openai
```

Создайте клиент `OpenAI`, указывающий на локальный сервер vLLM вместо серверов OpenAI. Параметр `api_key` требуется клиентом, но vLLM его не проверяет, поэтому подойдёт любая строка:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Затем отправьте запрос на завершение чата (chat completion). Используется тот же формат сообщений, что и в OpenAI API — список сообщений с ролями, такими как `"user"` и `"assistant"`. Установка `stream=True` означает, что ответ будет приходить постепенно, а не целиком:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Наконец, переберите полученные потоковые фрагменты и выведите каждый фрагмент текста по мере его поступления:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Прилагаемый скрипт [chat_with_model.py](assets/chat_with_model.py) содержит весь пример и доступен для скачивания.
