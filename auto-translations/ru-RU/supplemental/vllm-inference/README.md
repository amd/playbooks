## Обзор

vLLM — это высокопроизводительный движок инференса, разработанный для больших языковых моделей (LLM). Он обеспечивает оптимизированное обслуживание с непрерывной пакетной обработкой для высокой пропускной способности и OpenAI-совместимый API для бесшовной интеграции с приложениями. Это делает vLLM отличным решением для производственных развёртываний, где критически важны скорость и эффективность использования ресурсов.

Этот playbook научит вас обслуживать LLM с помощью контейнеризованного vLLM на интегрированном GPU и взаимодействовать с моделями через OpenAI Python API.

## Что вы узнаете

- Как настроить и запустить сервер vLLM с поддержкой AMD ROCm™
- Как взаимодействовать с моделями через OpenAI-совместимые конечные точки API
- Как отправлять запросы на локальный сервер с помощью `vllm-prompt`

## Установка необходимых программных компонентов

В этом playbook используется готовый образ контейнера, включающий vLLM, поддержку ROCm и вспомогательные скрипты для запуска сервера. Вам не нужно вручную устанавливать PyTorch, vLLM или локальные скрипты playbook.

Шаг установки vLLM на стороне хоста отсутствует. Запустите vLLM с помощью:

```bash
vllm-launch
```

Лаунчер запускает контейнер, нацеливается на интегрированный GPU и открывает локальный OpenAI-совместимый сервер vLLM. Кроме того, можно нажать на значок vLLM на панели задач.

## Быстрый старт

### 1. Убедитесь, что сервер vLLM запущен

Инициализация `vllm-launch` может занять несколько минут. После запуска сервер доступен по адресу `http://localhost:8001`. Оставьте терминал запуска открытым, так как сервер работает на переднем плане, затем откройте отдельный терминал для выполнения оставшихся шагов. В приведённых ниже примерах используется `Qwen/Qwen3-1.7B`; если ваш лаунчер настроен на другую модель, подставьте её идентификатор в запросы.

### 2. Отправьте запрос

Используйте предоставленный скрипт `vllm-prompt` для отправки запроса на локальный OpenAI-совместимый сервер vLLM:

```bash
vllm-prompt "Tell me a story"
```

### 3. Общайтесь с моделью через OpenAI Python API

Поскольку vLLM предоставляет OpenAI-совместимый API, вы можете использовать пакет Python `openai` для взаимодействия с ним.

Сначала создайте виртуальное окружение Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Установите пакет OpenAI
```bash
pip install openai
```

Создайте клиент `OpenAI`, направленный на локальный сервер vLLM вместо серверов OpenAI. Параметр `api_key` требуется клиенту, но vLLM его не проверяет, поэтому подойдёт любая строка:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Затем отправьте запрос на завершение чата. Он использует тот же формат сообщений, что и OpenAI API — список сообщений с ролями, такими как `"user"` и `"assistant"`. Установка `stream=True` означает, что ответ будет поступать постепенно, а не весь сразу:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Наконец, выполните итерацию по потоковым фрагментам и выводите каждую часть текста по мере её поступления:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Прилагаемый скрипт [chat_with_model.py](assets/chat_with_model.py) содержит полный пример и доступен для скачивания.
