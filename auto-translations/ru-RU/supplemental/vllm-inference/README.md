## Обзор

vLLM — это высокопроизводительный движок инференса, разработанный для больших языковых моделей (LLM). Он обеспечивает оптимизированное обслуживание с непрерывной пакетной обработкой (continuous batching) для высокой пропускной способности и предоставляет API, совместимый с OpenAI, для беспрепятственной интеграции с приложениями. Это делает vLLM отличным выбором для промышленного развёртывания, где критически важны скорость и эффективное использование ресурсов.

В этом руководстве вы узнаете, как обслуживать LLM с помощью контейнеризированного vLLM на встроенном GPU и взаимодействовать с моделями через OpenAI Python API.

## Чему вы научитесь

- Как настроить и запустить сервер vLLM с поддержкой AMD ROCm™
- Как взаимодействовать с моделями через конечные точки API, совместимые с OpenAI
- Как отправлять запросы на локальный сервер с помощью `vllm-prompt`

## Установка необходимого программного обеспечения

vLLM работает в предварительно собранном контейнере с ROCm и заранее подобранными зависимостями. Дополнительная установка не требуется.

Отдельный шаг установки vLLM на хосте отсутствует. Запустите vLLM с помощью:

```bash
vllm-launch
```

Скрипт запуска запускает контейнер, использует встроенный GPU и предоставляет локальный сервер vLLM, совместимый с OpenAI. Также можно щёлкнуть значок vLLM на панели задач.

## Быстрый старт

### 1. Убедитесь, что сервер vLLM запущен

Команде `vllm-launch` может потребоваться пара минут для инициализации всего необходимого. После запуска сервер будет доступен по адресу `http://localhost:8001`. Не закрывайте терминал запуска, так как сервер работает на переднем плане, а для остальных шагов откройте отдельный терминал. В примерах ниже используется `Qwen/Qwen3-1.7B`; если ваш скрипт запуска настроен на другую модель, укажите в запросах соответствующий идентификатор модели.

### 2. Отправка запроса

Используйте предоставленный скрипт `vllm-prompt`, чтобы отправить запрос на локальный сервер vLLM, совместимый с OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Общение с моделью через OpenAI Python API

Поскольку vLLM предоставляет API, совместимый с OpenAI, вы можете использовать пакет Python `openai` для взаимодействия с ним.

Сначала создайте виртуальное окружение Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Установите пакет OpenAI
```bash
pip install openai
```

Создайте клиент `OpenAI`, направленный на локальный сервер vLLM вместо серверов OpenAI. Параметр `api_key` требуется клиенту, но vLLM его не проверяет, поэтому подойдёт любая строка:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Затем отправьте запрос на завершение диалога (chat completion). Здесь используется тот же формат сообщений, что и в API OpenAI — список сообщений с ролями, такими как `"user"` и `"assistant"`. Установка `stream=True` означает, что ответ будет поступать постепенно, а не целиком сразу:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Наконец, переберите поступающие фрагменты потока и выведите каждый кусочек текста по мере его получения:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Прилагаемый скрипт [chat_with_model.py](assets/chat_with_model.py) содержит полный пример и может быть загружен.


## Выбор и настройка модели

По умолчанию `vllm-launch` обслуживает тестовую модель `Qwen/Qwen3-1.7B` на порту `8001`. Вы можете изменить модель, порт и параметры обслуживания vLLM без пересборки или редактирования контейнера.

### Модели, протестированные AMD

Следующие модели предварительно настроены и проверены AMD:

| Модель | Примечания |
|-------|-------|
| `Qwen/Qwen3-1.7B` | Модель по умолчанию. Лёгкая и быстро загружается. |
| `openai/gpt-oss-20b` | Более крупная модель для более качественных ответов. |

### Запуск другой модели

Передайте идентификатор модели с помощью `--model` (или `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### Изменение порта

Передайте порт выше 1024 с помощью `--port` (или `-p`); по умолчанию используется `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

Если вы измените порт, укажите в `base_url` вашего клиента тот же порт (например, `http://localhost:8080/v1`).

### Передача дополнительных параметров vLLM

Любые дополнительные аргументы передаются напрямую в vLLM, поэтому вы можете настраивать параметры обслуживания, такие как длина контекста или тип данных. Есть два способа их указать.

**Встроенно (inline)**, после параметров скрипта запуска:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**Постоянно**, в файле конфигурации по пути `~/.local/share/vLLM/vllm-launch.conf`. По умолчанию этот файл не существует — создайте его и добавьте свои аргументы в виде массива Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

Используйте `+=`, чтобы добавить аргументы к аргументам по умолчанию, а не заменять их:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

Чтобы в любой момент увидеть все параметры скрипта запуска, выполните:

```bash
vllm-launch --help
```

### Где хранятся модели

`vllm-launch` ищет модели в двух местах:

| Расположение | Путь |
|----------|------|
| Системные модели | `/var/cache/models` |
| Пользовательские модели | `~/.local/share/vLLM/models` |

Вы можете поместить загруженную модель в любую из этих директорий и запустить её, передав путь или идентификатор в `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **Примечание**: Ожидается, что запуск собственной загруженной модели таким способом будет работать после её размещения в одной из указанных выше директорий, однако этот сценарий пока официально не проверен AMD.
