# Конфигурация платформы

Этот документ описывает ожидаемые конфигурации платформы для запуска данного playbook.

## Необходимые приложения/фреймворки

### Windows/Linux

GAIA должна быть предварительно установлена согласно инструкциям, приведённым в [Руководстве по установке GAIA](../../dependencies/gaia.md).

Lemonade Server должен быть предварительно установлен согласно инструкциям, приведённым в [Руководстве по установке Lemonade](../../dependencies/lemonade.md).

## Необходимые модели

### Windows/Linux

Агент Hardware Advisor Agent использует **Qwen3-Coder-30B** для логического рассуждения агента. Эта модель загружается автоматически во время выполнения `gaia init`. Ручная загрузка моделей не требуется.
