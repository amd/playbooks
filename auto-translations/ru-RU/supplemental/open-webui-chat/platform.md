# Конфигурация платформы

Этот документ описывает ожидаемую конфигурацию платформы для запуска данного сценария.

## Необходимые приложения/фреймворки

### Windows/Linux
Lemonade должен быть предварительно установлен [отсюда](https://lemonade-server.ai/install_options.html).

- **Open WebUI** (веб-приложение фронтенда)
- **Lemonade Server** (серверная часть для работы с моделями)

> Этот сценарий запускает **Lemonade** (сервер/приложение Lemonade) **нативно**. **Open WebUI** запускается как **контейнер** на Linux (через Podman) и как **пакет Python** на Windows. Пакет `open-webui` PyPI поддерживает только Python ≤ 3.12, поэтому контейнер Linux позволяет избежать необходимости управлять более старыми версиями Python.

## Модели (в Lemonade)

Модели следует загружать в **приложении Lemonade** (с помощью встроенного менеджера моделей) или через команды управления моделями Lemonade (`lemonade pull <model_name>`). Этот сценарий предполагает, что рекомендованные ниже модели загружены и отображаются в конечной точке списка моделей.

Проверка доступности моделей:
- Откройте: `http://localhost:13305/api/v1/models`
- Загруженные модели будут перечислены в разделе `"data"`.

### Рекомендуемые модели

| Возможность | ID модели | Примечания |
|---|----|-----|
| LLM (текстовый ввод → текстовый вывод) | `Qwen3-4B-Hybrid` (или аналогичная) | Любая LLM-модель Lemonade для чата, завершения текста, написания кода или рассуждений |
| VLM (изображение → текст) | `Qwen3.5-4B-GGUF` (или любая модель из категории **Vision**) | Любая мультимодальная/визуальная модель, способная принимать изображения в качестве входных данных |
| Генерация изображений (текст → изображение) | `SDXL-Turbo` (или любая модель из категории **Image**) | Любая модель Stable Diffusion, генерирующая изображения по текстовому запросу |
| Аудио (речь → текст) | `Whisper-Large-v3` (или любая модель из категории **Audio**) | Любая ASR-модель, преобразующая аудио в текст |

## Используемые порты

- **Lemonade Server:** `http://localhost:13305`
- **Open WebUI:** `http://localhost:8080`

Если эти порты уже используются в вашей системе, измените их при запуске сервера(ов).
