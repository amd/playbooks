# Конфигурация платформы

В этом документе описывается ожидаемая конфигурация платформы для выполнения данного playbook.

## Необходимые приложения/фреймворки

### Windows/Linux
Lemonade должен быть предварительно установлен [отсюда](https://lemonade-server.ai/install_options.html). 

- **Open WebUI** (веб-приложение внешнего интерфейса)
- **Lemonade Server** (серверная часть, обслуживающая модели)

> Этот playbook запускает **Lemonade** (сервер/приложение Lemonade) **нативно**. **Open WebUI** запускается как **контейнер** в Linux (через Podman) и как **пакет Python** в Windows. Пакет PyPI `open-webui` поддерживает только Python ≤ 3.12, поэтому контейнер для Linux позволяет избежать необходимости управлять более старыми версиями Python.  

## Модели (в Lemonade)

Модели следует загружать внутри **приложения Lemonade** (с помощью встроенного Model Manager) или с помощью команд управления моделями Lemonade (`lemonade pull <model_name>`). Этот playbook предполагает, что указанные ниже рекомендуемые модели загружены и отображаются в конечной точке списка моделей.

Проверка доступности моделей:
- Откройте: `http://localhost:13305/api/v1/models`
- Загруженные модели будут перечислены в разделе `"data"`.

### Рекомендуемые модели

| Возможность | ID модели | Примечания |
|---|----|-----|
| LLM (текст на входе → текст на выходе) | `Qwen3-4B-Hybrid` (или аналогичная) | Любая LLM-модель Lemonade для чата, завершения текста, программирования или рассуждений |
| VLM (изображение → текст) | `Qwen3.5-4B-GGUF` (или любая модель из категории **Vision**) | Любая мультимодальная модель с поддержкой изображений, способная принимать изображения как часть входных данных |
| Генерация изображений (текст → изображение) | `SDXL-Turbo` (или любая модель из категории **Image**) | Любая модель Stable Diffusion, генерирующая изображения по текстовому запросу |
| Аудио (речь → текст) | `Whisper-Large-v3` (или любая модель из категории **Audio**) | Любая ASR-модель, преобразующая аудио в текст |
