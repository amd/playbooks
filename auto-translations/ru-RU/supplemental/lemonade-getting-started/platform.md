# Конфигурация платформы — Lemonade Local AI

Этот документ описывает предустановленное программное обеспечение, пути к моделям и специфичные для платформы предварительные требования, предполагаемые данным руководством.

## Предустановленное программное обеспечение

| Программное обеспечение | Версия | Назначение |
|----------|---------|---------|
| Lemonade Server | Последний релиз | Локальный LLM-сервер с API, совместимым с OpenAI |
| Python | 3.10–3.13 | Требуется для примера с использованием клиента OpenAI Python |

## Хранилище моделей по умолчанию

Модели, загруженные через Lemonade, хранятся в соответствии со спецификацией Hugging Face Hub:

| Платформа | Путь по умолчанию |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

Чтобы изменить расположение хранилища, установите переменную окружения `HF_HOME`.

## Требования к оборудованию

| Целевое оборудование | Требования |
|----------------|-------------|
| **CPU** | Любой современный процессор x86-64 (AMD или Intel) |
| **GPU (Vulkan)** | Любой GPU с поддержкой драйвера Vulkan |
| **GPU (ROCm)** | AMD Radeon RX серии 7000/9000 или Radeon PRO серии W7000; AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | Процессор AMD Ryzen AI 300 серии, Windows 11 |

## Требования к сети

- Для первоначальной загрузки модели требуется подключение к интернету (1–25 ГБ в зависимости от модели)
- После загрузки моделей интернет не требуется
