# Конфигурация платформы — Lemonade Local AI

Этот документ описывает предустановленное программное обеспечение, пути к моделям и специфические для платформы предварительные требования, используемые в данном руководстве.

## Предустановленное программное обеспечение

| Программное обеспечение | Версия | Назначение |
|----------|---------|---------|
| Lemonade Server | Последний релиз | Локальный LLM-сервер с OpenAI-совместимым API |
| Python | 3.10–3.13 | Требуется для примера с клиентом OpenAI на Python |

## Хранилище моделей по умолчанию

Модели, загруженные через Lemonade, хранятся в соответствии со спецификацией Hugging Face Hub:

| Платформа | Путь по умолчанию |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

Чтобы изменить расположение хранилища, задайте переменную окружения `HF_HOME`.

## Требования к оборудованию

| Целевое оборудование | Требования |
|----------------|-------------|
| **CPU** | Любой современный процессор x86-64 (AMD или Intel) |
| **GPU (Vulkan)** | Любой GPU с поддержкой драйвера Vulkan |
| **GPU (ROCm)** | AMD Radeon RX серии 7000/9000 или Radeon PRO W7000 серии; AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | Процессор AMD Ryzen AI серии 300, Windows 11 |

## Требования к сети

- Для первоначальной загрузки модели требуется подключение к интернету (от 1 до 25 ГБ в зависимости от модели)
- После загрузки моделей интернет не требуется
