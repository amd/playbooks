### n8n

<!-- @os:windows -->

1. Откройте PowerShell или командную строку
2. Установите n8n глобально с помощью npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Установите n8n глобально с помощью npm:
```bash
npm install -g n8n
```

> **Примечание**: Дополнительные варианты установки см. в [документации n8n](https://docs.n8n.io/hosting/installation/npm/).

<!-- @os:end -->
