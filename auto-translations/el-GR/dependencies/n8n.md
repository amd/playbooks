### n8n

<!-- @os:windows -->

1. Ανοίξτε το PowerShell ή το Command Prompt
2. Εγκαταστήστε το n8n καθολικά χρησιμοποιώντας το npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Εγκαταστήστε το n8n καθολικά χρησιμοποιώντας το npm:
```bash
npm install -g n8n
```

> **Σημείωση**: Ανατρέξτε στην [Τεκμηρίωση n8n](https://docs.n8n.io/hosting/installation/npm/) για περισσότερες επιλογές εγκατάστασης.

<!-- @os:end -->
