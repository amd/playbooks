## Επισκόπηση

Το vLLM είναι μια μηχανή συμπερασμού υψηλής απόδοσης σχεδιασμένη για μεγάλα γλωσσικά μοντέλα (LLMs). Παρέχει βελτιστοποιημένη εξυπηρέτηση με συνεχή ομαδοποίηση (continuous batching) για υψηλή απόδοση και ένα API συμβατό με OpenAI για απρόσκοπτη ενσωμάτωση εφαρμογών. Αυτό καθιστά το vLLM ιδανικό για αναπτύξεις παραγωγής όπου η ταχύτητα και η αποδοτική χρήση πόρων είναι κρίσιμες.

Αυτό το playbook σας διδάσκει πώς να εξυπηρετήσετε LLMs χρησιμοποιώντας containerized vLLM στην ενσωματωμένη GPU και να αλληλεπιδράσετε με μοντέλα μέσω του OpenAI Python API.

## Τι Θα Μάθετε

- Πώς να ρυθμίσετε και να ξεκινήσετε έναν διακομιστή vLLM με υποστήριξη AMD ROCm™
- Πώς να αλληλεπιδράσετε με μοντέλα μέσω τελικών σημείων API συμβατών με OpenAI
- Πώς να στέλνετε prompts στον τοπικό διακομιστή με το `vllm-prompt`

## Εγκατάσταση Απαραίτητου Λογισμικού

Αυτό το playbook χρησιμοποιεί μια προκατασκευασμένη εικόνα container που περιλαμβάνει το vLLM, υποστήριξη ROCm, και τα βοηθητικά scripts που απαιτούνται για την εκκίνηση του διακομιστή. Δεν χρειάζεται να εγκαταστήσετε χειροκίνητα το PyTorch, το vLLM, ή τοπικά scripts του playbook.

Δεν υπάρχει βήμα εγκατάστασης vLLM στον host. Ξεκινήστε το vLLM με:

```bash
vllm-launch
```

Ο launcher ξεκινά το container, στοχεύει την ενσωματωμένη GPU, και εκθέτει έναν τοπικό διακομιστή vLLM συμβατό με OpenAI. Εναλλακτικά, κάντε κλικ στο εικονίδιο vLLM στη γραμμή εργασιών.

## Γρήγορη Εκκίνηση

### 1. Επιβεβαιώστε ότι ο Διακομιστής vLLM Εκτελείται

Το `vllm-launch` ενδέχεται να χρειαστεί μερικά λεπτά για να αρχικοποιήσει τα πάντα. Μόλις ξεκινήσει, ο διακομιστής είναι διαθέσιμος στη διεύθυνση `http://localhost:8001`. Κρατήστε ανοιχτό το τερματικό εκκίνησης επειδή ο διακομιστής εκτελείται στο προσκήνιο, και στη συνέχεια ανοίξτε ένα ξεχωριστό τερματικό για τα υπόλοιπα βήματα. Τα παρακάτω παραδείγματα χρησιμοποιούν το `Qwen/Qwen3-1.7B`· εάν ο launcher σας είναι διαμορφωμένος για διαφορετικό μοντέλο, αντικαταστήστε αυτό το ID μοντέλου στα αιτήματα.

### 2. Στείλτε ένα Prompt

Χρησιμοποιήστε το παρεχόμενο script `vllm-prompt` για να στείλετε ένα αίτημα στον τοπικό διακομιστή vLLM συμβατό με OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Συνομιλήστε με το μοντέλο χρησιμοποιώντας το OpenAI Python API

Επειδή το vLLM εκθέτει ένα API συμβατό με OpenAI, μπορείτε να χρησιμοποιήσετε το πακέτο Python `openai` για να αλληλεπιδράσετε μαζί του.

Πρώτα, δημιουργήστε ένα εικονικό περιβάλλον Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Εγκαταστήστε το πακέτο OpenAI
```bash
pip install openai
```

Δημιουργήστε έναν πελάτη `OpenAI` που να δείχνει στον τοπικό διακομιστή vLLM αντί για τους διακομιστές του OpenAI. Το `api_key` απαιτείται από τον πελάτη, αλλά το vLLM δεν το επικυρώνει, οπότε οποιαδήποτε συμβολοσειρά λειτουργεί:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Στη συνέχεια, στείλτε ένα αίτημα ολοκλήρωσης συνομιλίας. Αυτό χρησιμοποιεί την ίδια μορφή μηνυμάτων με το OpenAI API — μια λίστα μηνυμάτων με ρόλους όπως `"user"` και `"assistant"`. Ο ορισμός `stream=True` σημαίνει ότι η απόκριση θα φτάνει σταδιακά αντί να φτάνει όλη μαζί:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Τέλος, επαναλάβετε πάνω από τα ροϊκά τμήματα (streamed chunks) και εκτυπώστε κάθε κομμάτι κειμένου καθώς φτάνει:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Το συμπεριλαμβανόμενο script [chat_with_model.py](assets/chat_with_model.py) περιέχει ολόκληρο το παράδειγμα και μπορεί να ληφθεί.

## Σύνοψη

Σε αυτό το playbook, μάθατε πώς να:

- Ξεκινήσετε containerized vLLM με υποστήριξη ROCm στην ενσωματωμένη GPU
- Ξεκινήσετε έναν διακομιστή vLLM με τελικά σημεία API συμβατά με OpenAI στη θύρα 8001
- Στείλετε prompts με το `vllm-prompt`
- Πραγματοποιήσετε κλήσεις API στον διακομιστή vLLM χρησιμοποιώντας τόσο αιτήματα ροής όσο και μη ροϊκά αιτήματα
- Αντιμετωπίσετε συνήθη προβλήματα με την εκκίνηση διακομιστή, τη μνήμη, και τις συνδέσεις πελάτη

Τώρα διαθέτετε μια containerized ανάπτυξη vLLM για την εξυπηρέτηση μεγάλων γλωσσικών μοντέλων με βελτιστοποιημένη απόδοση στην ενσωματωμένη GPU.

## Επόμενα Βήματα

- **Δοκιμάστε διαφορετικά μοντέλα** — Αντικαταστήστε το μοντέλο στη διαμόρφωση `vllm-launch` για να πειραματιστείτε με διαφορετικά LLMs και να συγκρίνετε την απόδοση.
- **Δημιουργήστε μια εφαρμογή** — Χρησιμοποιήστε το API συμβατό με OpenAI για να ενσωματώσετε το vLLM σε μια εφαρμογή Python, chatbot, ή ροή εργασίας αυτοματισμού.
- **Κάντε fine-tune και εξυπηρετήστε** — Κάντε fine-tune ένα μοντέλο χρησιμοποιώντας LoRA ή QLoRA, και στη συνέχεια αναπτύξτε το με το vLLM για βελτιστοποιημένο συμπερασμό.
