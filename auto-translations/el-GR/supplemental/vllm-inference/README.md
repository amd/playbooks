## Επισκόπηση

Το vLLM είναι μια μηχανή συμπερασμού υψηλής απόδοσης σχεδιασμένη για μεγάλα γλωσσικά μοντέλα (LLMs). Παρέχει βελτιστοποιημένη εξυπηρέτηση με συνεχή ομαδοποίηση (continuous batching) για υψηλή απόδοση και ένα API συμβατό με το OpenAI για απρόσκοπτη ενσωμάτωση εφαρμογών. Αυτό καθιστά το vLLM ιδανικό για αναπτύξεις παραγωγής όπου η ταχύτητα και η αποδοτικότητα πόρων είναι κρίσιμες.

Αυτό το εγχειρίδιο σας διδάσκει πώς να εξυπηρετήσετε LLMs χρησιμοποιώντας containerized vLLM στην ενσωματωμένη GPU και να αλληλεπιδράτε με μοντέλα μέσω του OpenAI Python API.

## Τι Θα Μάθετε

- Πώς να ρυθμίσετε και να εκκινήσετε έναν διακομιστή vLLM με υποστήριξη AMD ROCm™
- Πώς να αλληλεπιδράτε με μοντέλα μέσω endpoints API συμβατών με OpenAI
- Πώς να στέλνετε prompts στον τοπικό διακομιστή με το `vllm-prompt`

## Εγκατάσταση Προαπαιτούμενων Λογισμικού

Το vLLM εκτελείται σε ένα προκατασκευασμένο container με το ROCm και τις εξαρτήσεις του προ-αντιστοιχισμένες. Δεν απαιτείται επιπλέον εγκατάσταση.

Δεν υπάρχει βήμα εγκατάστασης vLLM στον host. Εκκινήστε το vLLM με:

```bash
vllm-launch
```

Το πρόγραμμα εκκίνησης ξεκινά το container, στοχεύει την ενσωματωμένη GPU και εκθέτει έναν τοπικό διακομιστή vLLM συμβατό με OpenAI. Εναλλακτικά, κάντε κλικ στο εικονίδιο vLLM στη γραμμή εργασιών.

## Γρήγορη Εκκίνηση

### 1. Επιβεβαιώστε ότι ο Διακομιστής vLLM Εκτελείται

Το `vllm-launch` ενδέχεται να χρειαστεί μερικά λεπτά για να αρχικοποιήσει τα πάντα. Μόλις ξεκινήσει, ο διακομιστής είναι διαθέσιμος στο `http://localhost:8001`. Κρατήστε το τερματικό εκκίνησης ανοιχτό επειδή ο διακομιστής εκτελείται στο προσκήνιο, και στη συνέχεια ανοίξτε ένα ξεχωριστό τερματικό για τα υπόλοιπα βήματα. Τα παρακάτω παραδείγματα χρησιμοποιούν το `Qwen/Qwen3-1.7B`· εάν το πρόγραμμα εκκίνησης είναι διαμορφωμένο για διαφορετικό μοντέλο, αντικαταστήστε αυτό το αναγνωριστικό μοντέλου στα αιτήματα.

### 2. Στείλτε ένα Prompt

Χρησιμοποιήστε το παρεχόμενο script `vllm-prompt` για να στείλετε ένα αίτημα στον τοπικό διακομιστή vLLM συμβατό με OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Συνομιλήστε με το μοντέλο χρησιμοποιώντας το OpenAI Python API

Δεδομένου ότι το vLLM εκθέτει ένα API συμβατό με OpenAI, μπορείτε να χρησιμοποιήσετε το πακέτο Python `openai` για να αλληλεπιδράσετε με αυτό.

Πρώτα, δημιουργήστε ένα εικονικό περιβάλλον Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->
<!-- @os:end -->

Εγκαταστήστε το πακέτο OpenAI
```bash
pip install openai
```

Δημιουργήστε έναν πελάτη `OpenAI` που να στοχεύει στον τοπικό διακομιστή vLLM αντί για τους διακομιστές του OpenAI. Το `api_key` απαιτείται από τον πελάτη, αλλά το vLLM δεν το επικυρώνει, οπότε οποιαδήποτε συμβολοσειρά λειτουργεί:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Στη συνέχεια, στείλτε ένα αίτημα ολοκλήρωσης συνομιλίας (chat completion). Αυτό χρησιμοποιεί την ίδια μορφή μηνυμάτων με το API του OpenAI — μια λίστα μηνυμάτων με ρόλους όπως `"user"` και `"assistant"`. Ο ορισμός `stream=True` σημαίνει ότι η απάντηση θα φτάνει σταδιακά αντί να φτάνει όλη μαζί:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Τέλος, επαναλάβετε πάνω στα τμήματα ροής (streamed chunks) και εκτυπώστε κάθε κομμάτι κειμένου καθώς φτάνει:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Το συμπεριλαμβανόμενο script [chat_with_model.py](assets/chat_with_model.py) περιέχει ολόκληρο το παράδειγμα και μπορεί να ληφθεί.


## Επιλογή και Διαμόρφωση ενός Μοντέλου

Από προεπιλογή, το `vllm-launch` εξυπηρετεί το `Qwen/Qwen3-1.7B` ως δοκιμαστικό μοντέλο στη θύρα `8001`. Μπορείτε να αλλάξετε το μοντέλο, τη θύρα και τις παραμέτρους εξυπηρέτησης του vLLM χωρίς να χρειάζεται να ξαναχτίσετε ή να επεξεργαστείτε το container.

### Μοντέλα που έχουν δοκιμαστεί από την AMD

Τα παρακάτω μοντέλα είναι προδιαμορφωμένα και επικυρωμένα από την AMD:

| Μοντέλο | Σημειώσεις |
|-------|-------|
| `Qwen/Qwen3-1.7B` | Προεπιλεγμένο μοντέλο. Ελαφρύ και γρήγορο στη φόρτωση. |
| `openai/gpt-oss-20b` | Μεγαλύτερο μοντέλο για απαντήσεις υψηλότερης ποιότητας. |

### Εκκίνηση διαφορετικού μοντέλου

Περάστε το αναγνωριστικό μοντέλου με `--model` (ή `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### Αλλαγή της θύρας

Περάστε μια θύρα πάνω από το 1024 με `--port` (ή `-p`)· η προεπιλογή είναι `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

Εάν αλλάξετε τη θύρα, κατευθύνετε το `base_url` του πελάτη σας στην ίδια θύρα (για παράδειγμα `http://localhost:8080/v1`).

### Πέρασμα επιπλέον παραμέτρων vLLM

Οποιαδήποτε επιπλέον ορίσματα προωθούνται απευθείας στο vLLM, οπότε μπορείτε να ρυθμίσετε τη συμπεριφορά εξυπηρέτησης, όπως το μήκος περιεχομένου (context length) ή τον τύπο δεδομένων. Υπάρχουν δύο τρόποι να τα παρέχετε.

**Ενσωματωμένα (Inline)**, μετά τις επιλογές του προγράμματος εκκίνησης:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**Μόνιμα (Persistently)**, σε ένα αρχείο διαμόρφωσης στο `~/.local/share/vLLM/vllm-launch.conf`. Αυτό το αρχείο δεν υπάρχει από προεπιλογή — δημιουργήστε το και προσθέστε τα ορίσματά σας ως πίνακα Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

Χρησιμοποιήστε το `+=` για να προσθέσετε στα προεπιλεγμένα ορίσματα αντί να τα αντικαταστήσετε:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

Για να δείτε όλες τις επιλογές του προγράμματος εκκίνησης ανά πάσα στιγμή, εκτελέστε:

```bash
vllm-launch --help
```

### Πού αποθηκεύονται τα μοντέλα

Το `vllm-launch` αναζητά μοντέλα σε δύο τοποθεσίες:

| Τοποθεσία | Διαδρομή |
|----------|------|
| Μοντέλα συστήματος | `/var/cache/models` |
| Μοντέλα χρήστη | `~/.local/share/vLLM/models` |

Μπορείτε να τοποθετήσετε ένα κατεβασμένο μοντέλο σε οποιονδήποτε από τους δύο καταλόγους και να το εκκινήσετε περνώντας τη διαδρομή ή το αναγνωριστικό του στο `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **Σημείωση**: Η εκτέλεση του δικού σας κατεβασμένου μοντέλου με αυτόν τον τρόπο αναμένεται να λειτουργήσει μόλις το μοντέλο τοποθετηθεί σε έναν από τους παραπάνω καταλόγους, αλλά αυτή η ροή εργασίας δεν έχει ακόμα επικυρωθεί επίσημα από την AMD.

## Σύνοψη

Σε αυτό το εγχειρίδιο, μάθατε πώς να:

- Εκκινείτε containerized vLLM με υποστήριξη ROCm στην ενσωματωμένη GPU
- Εκκινείτε έναν διακομιστή vLLM με endpoints API συμβατά με OpenAI στη θύρα 8001
- Στέλνετε prompts με το `vllm-prompt`
- Πραγματοποιείτε κλήσεις API στον διακομιστή vLLM χρησιμοποιώντας τόσο αιτήματα ροής (streaming) όσο και μη ροής (non-streaming)
- Αντιμετωπίζετε κοινά προβλήματα με την εκκίνηση του διακομιστή, τη μνήμη και τις συνδέσεις πελατών

Τώρα διαθέτετε μια containerized ανάπτυξη vLLM για την εξυπηρέτηση μεγάλων γλωσσικών μοντέλων με βελτιστοποιημένη απόδοση στην ενσωματωμένη GPU.

## Επόμενα Βήματα

- **Δοκιμάστε διαφορετικά μοντέλα** — Χρησιμοποιήστε το `vllm-launch --model <model>` για να πειραματιστείτε με διαφορετικά LLMs και να συγκρίνετε την απόδοση (δείτε [Επιλογή και Διαμόρφωση ενός Μοντέλου](#choosing-and-configuring-a-model)).
- **Δημιουργήστε μια εφαρμογή** — Χρησιμοποιήστε το API συμβατό με OpenAI για να ενσωματώσετε το vLLM σε μια εφαρμογή Python, ένα chatbot ή μια ροή εργασίας αυτοματισμού.
- **Fine-tune και εξυπηρετήστε** — Κάντε fine-tune σε ένα μοντέλο χρησιμοποιώντας LoRA ή QLoRA, και στη συνέχεια αναπτύξτε το με vLLM για βελτιστοποιημένο συμπερασμό.
