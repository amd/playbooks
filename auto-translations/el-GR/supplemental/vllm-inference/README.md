## Επισκόπηση

Το vLLM είναι μια μηχανή συμπερασμού υψηλής απόδοσης σχεδιασμένη για μεγάλα γλωσσικά μοντέλα (LLMs). Παρέχει βελτιστοποιημένη εξυπηρέτηση με συνεχή ομαδοποίηση (batching) για υψηλή απόδοση και ένα API συμβατό με OpenAI για απρόσκοπτη ενσωμάτωση εφαρμογών. Αυτό καθιστά το vLLM ιδανικό για παραγωγικές αναπτύξεις όπου η ταχύτητα και η αποδοτικότητα πόρων είναι κρίσιμες.

Αυτό το playbook σας διδάσκει πώς να εξυπηρετήσετε LLMs χρησιμοποιώντας containerized vLLM στην ενσωματωμένη GPU και να αλληλεπιδράσετε με μοντέλα μέσω του OpenAI Python API.

## Τι Θα Μάθετε

- Πώς να ρυθμίσετε και να ξεκινήσετε έναν διακομιστή vLLM με υποστήριξη AMD ROCm™
- Πώς να αλληλεπιδράσετε με μοντέλα μέσω των endpoints του API συμβατού με OpenAI
- Πώς να στέλνετε prompts στον τοπικό διακομιστή με το `vllm-prompt`

## Εγκατάσταση Προαπαιτούμενου Λογισμικού

Το vLLM εκτελείται σε ένα προκατασκευασμένο container με το ROCm και τις εξαρτήσεις του προεγκατεστημένες. Δεν απαιτείται πρόσθετη εγκατάσταση.

Δεν υπάρχει βήμα εγκατάστασης του vLLM στο host. Ξεκινήστε το vLLM με:

```bash
vllm-launch
```

Ο launcher ξεκινά το container, στοχεύει την ενσωματωμένη GPU και εκθέτει έναν τοπικό διακομιστή vLLM συμβατό με OpenAI. Εναλλακτικά, κάντε κλικ στο εικονίδιο vLLM στη γραμμή εργασιών.

## Γρήγορη Εκκίνηση

### 1. Επιβεβαιώστε ότι ο Διακομιστής vLLM Εκτελείται

Το `vllm-launch` ενδέχεται να χρειαστεί μερικά λεπτά για να αρχικοποιήσει τα πάντα. Μόλις ξεκινήσει, ο διακομιστής είναι διαθέσιμος στη διεύθυνση `http://localhost:8001`. Κρατήστε ανοιχτό το τερματικό εκκίνησης, καθώς ο διακομιστής εκτελείται στο προσκήνιο, και στη συνέχεια ανοίξτε ένα ξεχωριστό τερματικό για τα υπόλοιπα βήματα. Τα παρακάτω παραδείγματα χρησιμοποιούν το `Qwen/Qwen3-1.7B`· εάν ο launcher σας έχει ρυθμιστεί για διαφορετικό μοντέλο, αντικαταστήστε αυτό το ID μοντέλου στα αιτήματα.

### 2. Στείλτε ένα Prompt

Χρησιμοποιήστε το παρεχόμενο script `vllm-prompt` για να στείλετε ένα αίτημα στον τοπικό διακομιστή vLLM συμβατό με OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Συνομιλήστε με το μοντέλο χρησιμοποιώντας το OpenAI Python API

Καθώς το vLLM εκθέτει ένα API συμβατό με OpenAI, μπορείτε να χρησιμοποιήσετε το πακέτο Python `openai` για να αλληλεπιδράσετε μαζί του.

Πρώτα, δημιουργήστε ένα εικονικό περιβάλλον Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Εγκαταστήστε το πακέτο OpenAI
```bash
pip install openai
```

Δημιουργήστε έναν πελάτη `OpenAI` που να στοχεύει στον τοπικό διακομιστή vLLM αντί για τους διακομιστές του OpenAI. Το `api_key` απαιτείται από τον πελάτη, αλλά το vLLM δεν το επικυρώνει, οπότε οποιαδήποτε συμβολοσειρά λειτουργεί:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Στη συνέχεια, στείλτε ένα αίτημα ολοκλήρωσης συνομιλίας (chat completion). Αυτό χρησιμοποιεί την ίδια μορφή μηνυμάτων με το OpenAI API — μια λίστα μηνυμάτων με ρόλους όπως `"user"` και `"assistant"`. Ορίζοντας `stream=True`, η απόκριση θα φτάσει σταδιακά αντί όλη μαζί:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Τέλος, επαναλάβετε πάνω στα ροϊκά (streamed) τμήματα και εκτυπώστε κάθε κομμάτι κειμένου καθώς φτάνει:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Το συνοδευτικό script [chat_with_model.py](assets/chat_with_model.py) περιέχει ολόκληρο το παράδειγμα και μπορεί να ληφθεί.


## Επιλογή και Διαμόρφωση Μοντέλου

Από προεπιλογή, το `vllm-launch` εξυπηρετεί το `Qwen/Qwen3-1.7B` ως δοκιμαστικό μοντέλο στη θύρα `8001`. Μπορείτε να αλλάξετε το μοντέλο, τη θύρα και τις παραμέτρους εξυπηρέτησης του vLLM χωρίς να χρειαστεί εκ νέου δημιουργία ή επεξεργασία του container.

### Μοντέλα δοκιμασμένα από την AMD

Τα παρακάτω μοντέλα είναι προρυθμισμένα και επικυρωμένα από την AMD:

| Μοντέλο | Σημειώσεις |
|-------|-------|
| `Qwen/Qwen3-1.7B` | Προεπιλεγμένο μοντέλο. Ελαφρύ και γρήγορο στη φόρτωση. |
| `openai/gpt-oss-20b` | Μεγαλύτερο μοντέλο για αποκρίσεις υψηλότερης ποιότητας. |

### Εκκίνηση διαφορετικού μοντέλου

Περάστε το ID του μοντέλου με το `--model` (ή `-m`):

```bash
vllm-launch --model openai/gpt-oss-20b
```

### Αλλαγή της θύρας

Περάστε μια θύρα πάνω από το 1024 με το `--port` (ή `-p`)· η προεπιλογή είναι `8001`:

```bash
vllm-launch --port 8080 --model openai/gpt-oss-20b
```

Εάν αλλάξετε τη θύρα, κατευθύνετε το `base_url` του πελάτη σας στην ίδια θύρα (για παράδειγμα `http://localhost:8080/v1`).

### Πέρασμα επιπλέον παραμέτρων vLLM

Οποιαδήποτε πρόσθετα ορίσματα προωθούνται απευθείας στο vLLM, οπότε μπορείτε να ρυθμίσετε τη συμπεριφορά εξυπηρέτησης, όπως το μήκος περιεχομένου ή τον τύπο δεδομένων. Υπάρχουν δύο τρόποι για να τα παρέχετε.

**Ενσωματωμένα (Inline)**, μετά τις επιλογές του launcher:

```bash
vllm-launch --model openai/gpt-oss-20b --max-model-len 8192
```

**Μόνιμα**, σε ένα αρχείο διαμόρφωσης στο `~/.local/share/vLLM/vllm-launch.conf`. Αυτό το αρχείο δεν υπάρχει από προεπιλογή — δημιουργήστε το και προσθέστε τα ορίσματά σας ως πίνακα Bash:

```bash
VLLM_EXTRA_ARGS=(--max-model-len 8192 --dtype float16)
```

Χρησιμοποιήστε το `+=` για να προσθέσετε στα προεπιλεγμένα ορίσματα αντί να τα αντικαταστήσετε:

```bash
VLLM_EXTRA_ARGS+=(--max-model-len 8192)
```

Για να δείτε όλες τις επιλογές του launcher ανά πάσα στιγμή, εκτελέστε:

```bash
vllm-launch --help
```

### Πού αποθηκεύονται τα μοντέλα

Το `vllm-launch` αναζητά μοντέλα σε δύο τοποθεσίες:

| Τοποθεσία | Διαδρομή |
|----------|------|
| Μοντέλα συστήματος | `/var/cache/models` |
| Μοντέλα χρήστη | `~/.local/share/vLLM/models` |

Μπορείτε να τοποθετήσετε ένα ληφθέν μοντέλο σε οποιονδήποτε από τους δύο καταλόγους και να το εκκινήσετε περνώντας τη διαδρομή ή το ID του στο `--model`:

```bash
vllm-launch --model /var/cache/models/my-model
```

> **Σημείωση**: Η εκτέλεση του δικού σας ληφθέντος μοντέλου με αυτόν τον τρόπο αναμένεται να λειτουργήσει μόλις το μοντέλο τοποθετηθεί σε έναν από τους παραπάνω καταλόγους, αλλά αυτή η ροή εργασίας δεν έχει επικυρωθεί ακόμα επίσημα από την AMD.

## Σύνοψη

Σε αυτό το playbook, μάθατε πώς να:

- Ξεκινήσετε containerized vLLM με υποστήριξη ROCm στην ενσωματωμένη GPU
- Ξεκινήσετε έναν διακομιστή vLLM με endpoints API συμβατά με OpenAI στη θύρα 8001
- Στείλετε prompts με το `vllm-prompt`
- Πραγματοποιήσετε κλήσεις API στον διακομιστή vLLM χρησιμοποιώντας τόσο ροϊκά (streaming) όσο και μη ροϊκά αιτήματα
- Αντιμετωπίσετε συνήθη προβλήματα με την εκκίνηση διακομιστή, τη μνήμη και τις συνδέσεις πελάτη

Τώρα διαθέτετε μια containerized ανάπτυξη vLLM για την εξυπηρέτηση μεγάλων γλωσσικών μοντέλων με βελτιστοποιημένη απόδοση στην ενσωματωμένη GPU.

## Επόμενα Βήματα

- **Δοκιμάστε διαφορετικά μοντέλα** — Χρησιμοποιήστε το `vllm-launch --model <model>` για να πειραματιστείτε με διαφορετικά LLMs και να συγκρίνετε την απόδοση (δείτε [Επιλογή και Διαμόρφωση Μοντέλου](#choosing-and-configuring-a-model)).
- **Δημιουργήστε μια εφαρμογή** — Χρησιμοποιήστε το API συμβατό με OpenAI για να ενσωματώσετε το vLLM σε μια εφαρμογή Python, chatbot ή ροή εργασίας αυτοματισμού.
- **Fine-tune και εξυπηρετήστε** — Κάντε fine-tune ένα μοντέλο χρησιμοποιώντας LoRA ή QLoRA, και στη συνέχεια αναπτύξτε το με το vLLM για βελτιστοποιημένο συμπερασμό.
