## Επισκόπηση

Το vLLM είναι ένας μηχανισμός συμπερασμού υψηλής απόδοσης σχεδιασμένος για μεγάλα γλωσσικά μοντέλα (LLMs). Παρέχει βελτιστοποιημένη εξυπηρέτηση με συνεχή δέσμευση για υψηλή απόδοση και ένα API συμβατό με OpenAI για απρόσκοπτη ενσωμάτωση εφαρμογών. Αυτό καθιστά το vLLM ιδανικό για αναπτύξεις παραγωγής όπου η ταχύτητα και η αποδοτικότητα πόρων είναι κρίσιμες.

Αυτό το playbook σας διδάσκει πώς να εξυπηρετείτε LLMs χρησιμοποιώντας vLLM σε container στο ενσωματωμένο GPU και να αλληλεπιδράτε με μοντέλα μέσω του OpenAI Python API.

## Τι Θα Μάθετε

- Πώς να ρυθμίσετε και να εκκινήσετε έναν διακομιστή vLLM με υποστήριξη AMD ROCm™
- Πώς να αλληλεπιδράτε με μοντέλα μέσω τελικών σημείων API συμβατών με OpenAI
- Πώς να στέλνετε προτροπές στον τοπικό διακομιστή με `vllm-prompt`

## Εγκατάσταση Προαπαιτούμενων Λογισμικού

Αυτό το playbook χρησιμοποιεί μια προκατασκευασμένη εικόνα container που περιλαμβάνει το vLLM, υποστήριξη ROCm και τα βοηθητικά scripts που απαιτούνται για την εκκίνηση του διακομιστή. Δεν χρειάζεται να εγκαταστήσετε χειροκίνητα PyTorch, vLLM ή τοπικά scripts playbook.

Δεν υπάρχει βήμα εγκατάστασης vLLM στον κεντρικό υπολογιστή. Εκκινήστε το vLLM με:

```bash
vllm-launch
```

Ο εκκινητής ξεκινά το container, στοχεύει στο ενσωματωμένο GPU και εκθέτει έναν τοπικό διακομιστή vLLM συμβατό με OpenAI. Εναλλακτικά, κάντε κλικ στο εικονίδιο vLLM στη γραμμή εργασιών.

## Γρήγορη Εκκίνηση

### 1. Επιβεβαιώστε ότι ο Διακομιστής vLLM Εκτελείται

Η εντολή `vllm-launch` ενδέχεται να χρειαστεί μερικά λεπτά για να αρχικοποιήσει τα πάντα. Μόλις εκκινηθεί, ο διακομιστής είναι διαθέσιμος στη διεύθυνση `http://localhost:8001`. Κρατήστε το τερματικό εκκίνησης ανοιχτό επειδή ο διακομιστής εκτελείται στο προσκήνιο, και στη συνέχεια ανοίξτε ένα ξεχωριστό τερματικό για τα υπόλοιπα βήματα. Τα παρακάτω παραδείγματα χρησιμοποιούν `Qwen/Qwen3-1.7B`· εάν ο εκκινητής σας είναι διαμορφωμένος για διαφορετικό μοντέλο, αντικαταστήστε το αναγνωριστικό αυτού του μοντέλου στα αιτήματα.

### 2. Αποστολή Προτροπής

Χρησιμοποιήστε το παρεχόμενο script `vllm-prompt` για να στείλετε ένα αίτημα στον τοπικό διακομιστή vLLM συμβατό με OpenAI:

```bash
vllm-prompt "Tell me a story"
```

### 3. Συνομιλία με το μοντέλο χρησιμοποιώντας το OpenAI Python API

Εφόσον το vLLM εκθέτει ένα API συμβατό με OpenAI, μπορείτε να χρησιμοποιήσετε το πακέτο Python `openai` για να αλληλεπιδράσετε μαζί του.

Αρχικά, δημιουργήστε ένα εικονικό περιβάλλον Python:

<!-- @os:linux -->
<!-- @device:halo_box -->
```bash
sudo apt install -y python3-venv
python3 -m venv vllm-env
source vllm-env/bin/activate
```
<!-- @device:end -->

Εγκαταστήστε το πακέτο OpenAI
```bash
pip install openai
```

Δημιουργήστε έναν πελάτη `OpenAI` που να δείχνει στον τοπικό διακομιστή vLLM αντί για τους διακομιστές του OpenAI. Το `api_key` απαιτείται από τον πελάτη αλλά το vLLM δεν το επαληθεύει, οπότε οποιαδήποτε συμβολοσειρά λειτουργεί:

```python
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8001/v1",
    api_key="EMPTY",
)
```

Στη συνέχεια, στείλτε ένα αίτημα ολοκλήρωσης συνομιλίας. Αυτό χρησιμοποιεί την ίδια μορφή μηνυμάτων με το OpenAI API — μια λίστα μηνυμάτων με ρόλους όπως `"user"` και `"assistant"`. Η ρύθμιση `stream=True` σημαίνει ότι η απόκριση θα φτάσει σταδιακά αντί για όλη μαζί:

```python
response = client.chat.completions.create(
    model="Qwen/Qwen3-1.7B",
    messages=[
        {"role": "user", "content": "Tell me a short story"},
    ],
    max_tokens=2048,  # Maximum number of tokens the model will generate in its response
    stream=True,
)
```

Τέλος, επαναλάβετε πάνω στα τμήματα ροής και εκτυπώστε κάθε κομμάτι κειμένου καθώς φτάνει:

```python
for chunk in response:
    content = chunk.choices[0].delta.content
    if content:
        print(content, end="", flush=True)
```

Το συμπεριλαμβανόμενο script [chat_with_model.py](assets/chat_with_model.py) περιέχει ολόκληρο το παράδειγμα και μπορεί να ληφθεί.

## Σύνοψη

Σε αυτό το playbook, μάθατε πώς να:

- Εκκινείτε vLLM σε container με υποστήριξη ROCm στο ενσωματωμένο GPU
- Εκκινείτε έναν διακομιστή vLLM με τελικά σημεία API συμβατά με OpenAI στη θύρα 8001
- Στέλνετε προτροπές με `vllm-prompt`
- Πραγματοποιείτε κλήσεις API στον διακομιστή vLLM χρησιμοποιώντας αιτήματα ροής και μη ροής
- Αντιμετωπίζετε συνηθισμένα προβλήματα με την εκκίνηση διακομιστή, τη μνήμη και τις συνδέσεις πελατών

Διαθέτετε πλέον μια ανάπτυξη vLLM σε container για την εξυπηρέτηση μεγάλων γλωσσικών μοντέλων με βελτιστοποιημένη απόδοση στο ενσωματωμένο GPU.

## Επόμενα Βήματα

- **Δοκιμάστε διαφορετικά μοντέλα** — Αλλάξτε το μοντέλο στη διαμόρφωση `vllm-launch` για να πειραματιστείτε με διαφορετικά LLMs και να συγκρίνετε την απόδοση.
- **Δημιουργήστε μια εφαρμογή** — Χρησιμοποιήστε το API συμβατό με OpenAI για να ενσωματώσετε το vLLM σε μια εφαρμογή Python, chatbot ή ροή εργασίας αυτοματισμού.
- **Βελτιστοποιήστε και εξυπηρετήστε** — Βελτιστοποιήστε ένα μοντέλο χρησιμοποιώντας LoRA ή QLoRA, και στη συνέχεια αναπτύξτε το με vLLM για βελτιστοποιημένο συμπέρασμα.
