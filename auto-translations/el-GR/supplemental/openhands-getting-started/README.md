# Lemonade Server: Χρήση OpenHands σε Agent Canvas

## Επισκόπηση

Το [OpenHands](https://github.com/All-Hands-AI/OpenHands) είναι ένας πράκτορας λογισμικού AI
που μπορεί να γράφει κώδικα, να εκτελεί εντολές, να περιηγείται στο διαδίκτυο και να επεξεργάζεται αρχεία σε έναν πραγματικό
χώρο εργασίας. Αντί να αντιγράφετε προτάσεις από ένα παράθυρο συνομιλίας, κατευθύνετε τον
πράκτορα σε έναν φάκελο έργου και τον αφήνετε να κάνει τη δουλειά: υλοποίηση μιας δυνατότητας, διόρθωση ενός
σφάλματος, δημιουργία δοκιμών, ή επεξήγηση μιας βάσης κώδικα.

Το [Agent Canvas](https://github.com/OpenHands/agent-canvas) είναι το προτεινόμενο
περιβάλλον χρήστη φυλλομετρητή για την εκτέλεση του OpenHands. Μια μοναδική εντολή `agent-canvas` ξεκινά
τον διακομιστή πράκτορα, το backend αυτοματισμού, και το frontend ιστού μαζί, ώστε να μπορείτε
να οδηγήσετε μια συνομιλία με τον πράκτορα από τον φυλλομετρητή σας.

Για να διατηρήσετε τα πάντα στο σύστημά σας AMD, ο πράκτορας επικοινωνεί με ένα τοπικό μοντέλο που εξυπηρετείται
από τον Lemonade Server. Το Lemonade εκθέτει αυτό το μοντέλο μέσω ενός συμβατού με OpenAI
API, ώστε το Agent Canvas να μπορεί να το ρυθμίσει όπως κάθε άλλο τελικό σημείο τύπου OpenAI
ενώ το μοντέλο, ο κώδικάς σας, και το πλαίσιο της συνομιλίας παραμένουν όλα στο
μηχάνημά σας.

Σε αυτό το playbook, θα ξεκινήσετε ένα τοπικό μοντέλο, θα εκκινήσετε το Agent Canvas, θα το κατευθύνετε
σε αυτό το μοντέλο, και θα εκτελέσετε την πρώτη σας εργασία κωδικοποίησης σε έναν πραγματικό φάκελο έργου.

## Τι Θα Μάθετε

- Πώς να ξεκινήσετε τον Lemonade Server και να επιβεβαιώσετε ότι ένα τοπικό μοντέλο απαντά σε αιτήματα συνομιλίας
- Πώς να εγκαταστήσετε και να εκκινήσετε το Agent Canvas από το πακέτο npm
- Πώς να ρυθμίσετε το Agent Canvas ώστε να χρησιμοποιεί ένα τοπικό μοντέλο Lemonade ως το LLM
- Πώς να ξεκινήσετε μια συνομιλία OpenHands και να παρακολουθήσετε τον πράκτορα να επεξεργάζεται αρχεία και να εκτελεί
  εντολές σε έναν χώρο εργασίας
- Πώς να αναθεωρήσετε τι άλλαξε ο πράκτορας και να τον καθοδηγήσετε με μηνύματα παρακολούθησης

## 1. Εκκίνηση του Lemonade Server

Ξεκινήστε το μοντέλο από το Lemonade CLI:

```bash
lemonade config set llamacpp.backend=vulkan
lemonade config set ctx_size=65536
lemonade run "Qwen3.6-35B-A3B-GGUF"
```

Το Lemonade εκθέτει ένα συμβατό με OpenAI API στη διεύθυνση:

```text
http://127.0.0.1:13305/api/v1
```



## 2. Επαλήθευση του Τοπικού Μοντέλου

Επιβεβαιώστε ότι το Lemonade μπορεί να εξυπηρετήσει το επιλεγμένο μοντέλο:

```bash
curl -s "http://127.0.0.1:13305/api/v1/models" | python3 -m json.tool
```

Στη συνέχεια στείλτε ένα μικρό αίτημα συνομιλίας:

```bash
curl -sS "http://127.0.0.1:13305/api/v1/chat/completions" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "Qwen3.6-35B-A3B-GGUF",
    "messages": [
      {"role": "user", "content": "Reply with exactly: OK"}
    ],
    "temperature": 0,
    "max_tokens": 64
  }' | python3 -m json.tool
```

Εάν αυτό επιστρέψει έναν πίνακα `choices`, το Lemonade είναι έτοιμο για το Agent Canvas.

## 3. Εγκατάσταση και Εκκίνηση του Agent Canvas

Εγκαταστήστε το δημοσιευμένο πακέτο Agent Canvas καθολικά:

```bash
npm install -g @openhands/agent-canvas
```

Στη συνέχεια ξεκινήστε την πλήρη στοίβα από ένα τερματικό:

```bash
agent-canvas
```

Από προεπιλογή, το Agent Canvas ξεκινά στη διεύθυνση `http://localhost:8000`. Ανοίξτε αυτή τη διεύθυνση URL στον
φυλλομετρητή σας. Εάν η θύρα 8000 χρησιμοποιείται ήδη, περάστε `--port` (ή `-p`) όταν
εκκινείτε το Agent Canvas:

```bash
agent-canvas --port 3000
```

Η ίδια εντολή λειτουργεί στο PowerShell στα Windows. Στη συνέχεια ανοίξτε
`http://localhost:3000` αντ' αυτού. Το προεπιλεγμένο τοπικό backend θα πρέπει να εμφανίζεται ως
υγιές στην αρχική οθόνη.

Η εντολή `agent-canvas` ξεκινά τον διακομιστή πράκτορα, το backend αυτοματισμού, και
το frontend ιστού μαζί. Χρειάζεστε μόνο αυτή τη μία εντολή για να εκτελέσετε το OpenHands
τοπικά.

## 4. Ρύθμιση του Τοπικού LLM

Στην πρώτη εκκίνηση, το Agent Canvas ανοίγει μια ροή ενσωμάτωσης. Σε αυτή τη ροή:

1. Διατηρήστε το **OpenHands** επιλεγμένο ως τον πράκτορα και κάντε κλικ στο **Next**.
2. Στο **Set up your LLM**, επιλέξτε **Advanced**.
3. Διατηρήστε το **Authentication** ρυθμισμένο σε **API key**.
4. Ρυθμίστε το **Custom Model** σε `openai/Qwen3.6-35B-A3B-GGUF`.
5. Ρυθμίστε το **Base URL** σε `http://127.0.0.1:13305/api/v1`.
6. Για το **API Key**, εισαγάγετε ένα οποιοδήποτε μη κενό σύμβολο κράτησης θέσης όπως `lemonade-local`.
   Το Lemonade δεν απαιτεί πραγματικό κλειδί, αλλά ο πελάτης OpenHands χρειάζεται μια τιμή
   για να στείλει.
7. Κάντε κλικ στο **Next**.

Οι ολοκληρωμένες ρυθμίσεις Advanced θα πρέπει να μοιάζουν κάπως έτσι. Το πεδίο κλειδιού API
είναι κρυμμένο από το περιβάλλον χρήστη.

![Ρυθμίσεις LLM Advanced πρώτης χρήσης του Agent Canvas με το μοντέλο Lemonade και το τοπικό base URL](assets/01-llm-advanced-settings.png)

Το Agent Canvas αποθηκεύει αυτές τις τιμές ως προφίλ LLM. Εάν η έκδοσή σας σάς ζητά να
ονομάσετε αυτό το προφίλ, χρησιμοποιήστε ένα όνομα χωρίς κενά όπως `lemonade-local`. Εάν αλλάξετε
μοντέλα αργότερα, ανοίξτε **Settings > LLM** και ενημερώστε τα ίδια πεδία Advanced. Μπορείτε
να αλλάξετε αποθηκευμένα προφίλ από την είσοδο συνομιλίας με την εντολή `/model`.

## 5. Άνοιγμα ενός Χώρου Εργασίας

Ο πράκτορας μπορεί μόνο να διαβάζει και να τροποποιεί αρχεία μέσα σε έναν χώρο εργασίας που επιλέγετε. Πριν
ξεκινήσετε μια εργασία, κατευθύνετε το Agent Canvas στον φάκελο έργου σας:

1. Από την αρχική οθόνη, επιλέξτε **Open Workspace**.
2. Επιλέξτε τον φάκελο που περιέχει το έργο σας (για παράδειγμα, ένα αποθετήριο git
   που θέλετε να εργαστεί ο πράκτορας).
3. Ξεκινήστε μια νέα συνομιλία σε αυτόν τον χώρο εργασίας.

Ό,τι κάνει ο πράκτορας—ανάγνωση αρχείων, εκτέλεση εντολών, επεξεργασία κώδικα—περιορίζεται
σε αυτόν τον χώρο εργασίας.

![Αρχική σελίδα Agent Canvas μετά την ενσωμάτωση](assets/02-agent-canvas-home.png)
## 6. Εκτελέστε την Πρώτη σας Εργασία Κωδικοποίησης

Με τον χώρο εργασίας ανοιχτό και το τοπικό LLM επιλεγμένο, πληκτρολογήστε μια συγκεκριμένη εργασία στη συνομιλία. Μια καλή πρώτη εργασία είναι μικρή και επαληθεύσιμη, για παράδειγμα:

```text
Create a new file called hello.py that defines a function greet(name) that
returns "Hello, {name}!", and add a small test that prints greet("World")
when run as a script.
```

Παρακολουθήστε το χρονοδιάγραμμα της συνομιλίας. Το OpenHands θα:

- Διαβάσει τον χώρο εργασίας για να κατανοήσει τη διάταξη.
- Δημιουργήσει το `hello.py` με τη ζητούμενη συνάρτηση και το τμήμα δοκιμής.
- Προαιρετικά εκτελέσει `python3 hello.py` για να επαληθεύσει την έξοδο.
- Αναφέρει τι έκανε και οποιαδήποτε έξοδο εντολής στη συνομιλία.

Θα πρέπει να δείτε το νέο αρχείο να εμφανίζεται στον χώρο εργασίας, και το τελικό μήνυμα του agent θα πρέπει να περιγράφει την αλλαγή που έκανε. Αυτή είναι η στιγμή της ανταμοιβής: ο agent έγραψε και εκτέλεσε πραγματικό κώδικα στον φάκελο του project σας.

## 7. Ελέγξτε και Καθοδηγήστε τον Agent

Αφού ο agent ολοκληρώσει ένα βήμα, ελέγξτε τη δουλειά του πριν αποδεχτείτε το επόμενο:

- **Αλλαγές αρχείων**: χρησιμοποιήστε τον περιηγητή αρχείων του χώρου εργασίας ή την προβολή διαφορών (diff view) του agent για να δείτε ακριβώς τι προστέθηκε, άλλαξε ή διαγράφηκε.
- **Έξοδος εντολών**: αναπτύξτε οποιαδήποτε εντολή εκτέλεσε ο agent για να δείτε το stdout, το stderr και τον κωδικό εξόδου.
- **Επόμενα βήματα**: αν το αποτέλεσμα δεν είναι αυτό που θέλατε, απαντήστε στην ίδια συνομιλία με μια διόρθωση. Ο agent διατηρεί το προηγούμενο πλαίσιο και επαναλαμβάνει τη διαδικασία στα ίδια αρχεία.

Για παράδειγμα, αν η δοκιμή δεν εκτύπωσε τον αναμενόμενο χαιρετισμό, απαντήστε:

```text
The script did not print anything. Run python3 hello.py and fix it so the
greet("World") test prints to stdout.
```

Ο agent θα διαβάσει ξανά το αρχείο, θα εκτελέσει την εντολή, θα διαγνώσει το πρόβλημα και θα επεξεργαστεί ξανά το αρχείο—όλα στην ίδια συνομιλία.

## Αντιμετώπιση Προβλημάτων

- **Το `agent-canvas` δεν βρίσκεται στο PATH:** επανεγκαταστήστε με
  `npm install -g @openhands/agent-canvas` και επιβεβαιώστε ότι ο κατάλογος του καθολικού δυαδικού αρχείου npm βρίσκεται στο PATH σας. Στα Windows, εκτελέστε `npm config get prefix`· ο κατάλογος που επιστρέφεται, συνήθως `%APPDATA%\npm` ή `%USERPROFILE%\.npm-global`, πρέπει να βρίσκεται στο PATH χρήστη σας πριν το `agent-canvas` μπορεί να εκκινηθεί από ένα νέο τερματικό.
- **Η εντολή `npm install -g` αποτυγχάνει με σφάλμα δικαιωμάτων:** ρυθμίστε έναν καθολικό κατάλογο npm που ανήκει στον χρήστη, στη συνέχεια ανοίξτε ξανά το τερματικό και εγκαταστήστε ξανά το Agent Canvas.

  <!-- @os:linux -->
  ```bash
  mkdir -p ~/.npm-global
  npm config set prefix ~/.npm-global
  echo 'export PATH="$HOME/.npm-global/bin:$PATH"' >> ~/.profile
  . ~/.profile
  npm install -g @openhands/agent-canvas
  ```
  <!-- @os:end -->

  <!-- @os:windows -->
  ```powershell
  New-Item -ItemType Directory -Force "$env:USERPROFILE\.npm-global"
  npm config set prefix "$env:USERPROFILE\.npm-global"
  $env:Path = "$env:USERPROFILE\.npm-global;$env:Path"
  npm install -g @openhands/agent-canvas
  ```

  Για να κάνετε την αλλαγή του PATH στα Windows μόνιμη, προσθέστε το `%USERPROFILE%\.npm-global` στο PATH χρήστη σας μέσω **Ρυθμίσεις > Σύστημα > Σχετικά > Ρυθμίσεις για προχωρημένους συστήματος > Μεταβλητές περιβάλλοντος**, και ανοίξτε ένα νέο τερματικό.
  <!-- @os:end -->
- **Η διεπαφή χρήστη φορτώνει αλλά το backend εμφανίζεται μη υγιές:** περιμένετε λίγα δευτερόλεπτα ώστε ο διακομιστής agent να ολοκληρώσει την εκκίνηση, στη συνέχεια ανανεώστε τη σελίδα. Αν παραμένει μη υγιές, επανεκκινήστε το `agent-canvas` και ελέγξτε την έξοδο του τερματικού για σφάλματα.
- **Τα αιτήματα συνομιλίας του Lemonade αποτυγχάνουν με σφάλμα σύνδεσης:** επιβεβαιώστε ότι το `curl -fsS "http://127.0.0.1:13305/api/v1/health"` πετυχαίνει και ότι το Lemonade εξακολουθεί να εξυπηρετεί το μοντέλο με το `lemonade status`.
- **Ο agent εμφανίζει σφάλμα μήκους πλαισίου ή ορίου token:** επανεκκινήστε το Lemonade με μεγαλύτερο `ctx_size` (για παράδειγμα `ctx_size=65536`), και ξεκινήστε μια νέα συνομιλία ώστε ο agent να μη μεταφέρει υπερβολικά μεγάλο ιστορικό.
- **Ο agent παράγει επεξεργασίες χαμηλής ποιότητας ή ημιτελείς:** αλλάξτε σε μεγαλύτερο μοντέλο στο Lemonade, ή δώστε στον agent μια μικρότερη, πιο συγκεκριμένη εργασία και αφήστε τον να την ολοκληρώσει πριν ζητήσετε την επόμενη αλλαγή.
- **Το `uv` λείπει:** εγκαταστήστε το από
  [τον οδηγό εγκατάστασης uv](https://docs.astral.sh/uv/getting-started/installation/).
  Το Agent Canvas χρησιμοποιεί το `uv` για τη διαχείριση του περιβάλλοντος Python του διακομιστή agent.

## Επόμενα Βήματα

- Δοκιμάστε μια μεγαλύτερη εργασία στον ίδιο χώρο εργασίας, όπως η προσθήκη ενός αρχείου unit test ή η διόρθωση ενός γνωστού σφάλματος, και ελέγξτε το diff του agent πριν διατηρήσετε την αλλαγή.
- Συνδέστε έναν διακομιστή MCP όπως το GitHub ή το Slack κάτω από το **Customize** ώστε ο agent να μπορεί να διαβάζει issues ή να δημοσιεύει ενημερώσεις ενώ εργάζεται.
- Αποθηκεύστε πολλαπλά προφίλ LLM (ένα γρήγορο μικρό μοντέλο και ένα ισχυρότερο μεγάλο μοντέλο) και εναλλάσσεστε μεταξύ τους με το `/model` κατά τη διάρκεια της συνομιλίας.
- Προχωρήστε στο [OpenHands automations](https://docs.openhands.dev/openhands/usage/automations/overview) για να μετατρέψετε επαναλαμβανόμενους κύκλους ανάπτυξης σε προγραμματισμένες ή βασισμένες σε συμβάντα εκτελέσεις agent.
