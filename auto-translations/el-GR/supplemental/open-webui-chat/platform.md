# Διαμόρφωση Πλατφόρμας

Αυτό το έγγραφο περιγράφει την αναμενόμενη διαμόρφωση πλατφόρμας για την εκτέλεση αυτού του playbook.

## Απαιτούμενες Εφαρμογές/Frameworks

### Windows/Linux
Το Lemonade θα πρέπει να είναι προεγκατεστημένο από [εδώ](https://lemonade-server.ai/install_options.html).

- **Open WebUI** (εφαρμογή web frontend)
- **Lemonade Server** (διακομιστής μοντέλων backend)

> Αυτό το playbook εκτελεί το **Lemonade** (Lemonade server/app) **εγγενώς**. Το **Open WebUI** εκτελείται ως **container** στο Linux (μέσω Podman) και ως **πακέτο Python** στα Windows. Το πακέτο `open-webui` PyPI υποστηρίζει μόνο Python ≤ 3.12, οπότε το container Linux αποφεύγει την ανάγκη διαχείρισης παλαιότερων εκδόσεων Python.

## Μοντέλα (στο Lemonade)

Τα μοντέλα θα πρέπει να ληφθούν μέσα από την **εφαρμογή Lemonade** (χρησιμοποιώντας τον ενσωματωμένο Model Manager) ή μέσω των εντολών διαχείρισης μοντέλων του Lemonade (`lemonade pull <model_name>`). Αυτό το playbook προϋποθέτει ότι τα παρακάτω προτεινόμενα μοντέλα έχουν ληφθεί και εμφανίζονται στο endpoint της λίστας μοντέλων.

Έλεγχος διαθεσιμότητας μοντέλων:
- Άνοιγμα: `http://localhost:13305/api/v1/models`
- Τα ληφθέντα μοντέλα θα εμφανίζονται στο `"data"`.

### Προτεινόμενα μοντέλα

| Δυνατότητα | Model ID | Σημειώσεις |
|---|----|-----|
| LLM (Είσοδος κειμένου → Έξοδος κειμένου) | `Qwen3-4B-Hybrid` (ή παρόμοιο) | Οποιοδήποτε μοντέλο LLM του Lemonade για chat, συμπλήρωση κειμένου, προγραμματισμό ή συλλογισμό |
| VLM (Εικόνα → Κείμενο) | `Qwen3.5-4B-GGUF` (ή οποιοδήποτε μοντέλο στην κατηγορία **Vision**) | Οποιοδήποτε πολυτροπικό/οπτικά ικανό μοντέλο που μπορεί να δέχεται εικόνες ως μέρος της εισόδου του |
| Δημιουργία Εικόνας (Κείμενο → Εικόνα) | `SDXL-Turbo` (ή οποιοδήποτε μοντέλο στην κατηγορία **Image**) | Οποιοδήποτε μοντέλο Stable Diffusion που δημιουργεί εικόνες από μια προτροπή κειμένου |
| Ήχος (Ομιλία → Κείμενο) | `Whisper-Large-v3` (ή οποιοδήποτε μοντέλο στην κατηγορία **Audio**) | Οποιοδήποτε μοντέλο ASR που μετατρέπει ήχο σε κείμενο |
