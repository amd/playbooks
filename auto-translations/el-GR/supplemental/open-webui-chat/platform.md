# Ρύθμιση πλατφόρμας

Αυτό το έγγραφο περιγράφει την αναμενόμενη ρύθμιση πλατφόρμας για την εκτέλεση αυτού του playbook.

## Απαιτούμενες εφαρμογές/πλαίσια εργασίας

### Windows/Linux
Το Lemonade θα πρέπει να είναι προεγκατεστημένο από [εδώ](https://lemonade-server.ai/install_options.html). 

- **Open WebUI** (εφαρμογή web frontend)
- **Lemonade Server** (backend model server)

> Αυτό το playbook εκτελεί το **Lemonade** (Lemonade server/app) **εγγενώς (natively)**. Το **Open WebUI** εκτελείται ως **container** σε Linux (μέσω Podman) και ως **πακέτο Python** σε Windows. Το πακέτο PyPI `open-webui` υποστηρίζει μόνο Python ≤ 3.12, οπότε το container σε Linux αποφεύγει την ανάγκη διαχείρισης παλαιότερων εκδόσεων Python.  

## Μοντέλα (στο Lemonade)

Τα μοντέλα θα πρέπει να γίνονται λήψη μέσα από την **εφαρμογή Lemonade** (χρησιμοποιώντας τον ενσωματωμένο Model Manager) ή μέσω των εντολών διαχείρισης μοντέλων του Lemonade (`lemonade pull <model_name>`). Αυτό το playbook υποθέτει ότι τα παρακάτω προτεινόμενα μοντέλα έχουν γίνει λήψη και εμφανίζονται στο endpoint λίστας μοντέλων.

Έλεγχος διαθεσιμότητας μοντέλων:
- Ανοίξτε: `http://localhost:13305/api/v1/models`
- Τα μοντέλα που έχουν γίνει λήψη θα εμφανίζονται κάτω από το `"data"`.

### Προτεινόμενα μοντέλα

| Δυνατότητα | Model ID | Σημειώσεις |
|---|----|-----|
| LLM (Είσοδος κειμένου → Έξοδος κειμένου) | `Qwen3-4B-Hybrid` (ή παρόμοιο) | Οποιοδήποτε μοντέλο LLM του Lemonade για συνομιλία, συμπλήρωση κειμένου, κωδικοποίηση ή συλλογιστική |
| VLM (Εικόνα → Κείμενο) | `Qwen3.5-4B-GGUF` (ή οποιοδήποτε μοντέλο στην κατηγορία **Vision**) | Οποιοδήποτε πολυτροπικό μοντέλο με δυνατότητα όρασης που μπορεί να δεχτεί εικόνες ως μέρος της εισόδου του |
| Δημιουργία εικόνας (Κείμενο → Εικόνα) | `SDXL-Turbo` (ή οποιοδήποτε μοντέλο στην κατηγορία **Image**) | Οποιοδήποτε μοντέλο Stable Diffusion που δημιουργεί εικόνες από μια προτροπή κειμένου |
| Ήχος (Ομιλία → Κείμενο) | `Whisper-Large-v3` (ή οποιοδήποτε μοντέλο στην κατηγορία **Audio**) | Οποιοδήποτε μοντέλο ASR που μετατρέπει ήχο σε κείμενο |

## Θύρες που χρησιμοποιούνται

- **Lemonade Server:** `http://localhost:13305`
- **Open WebUI:** `http://localhost:8080`

Εάν αυτές οι θύρες χρησιμοποιούνται ήδη στο σύστημά σας, αλλάξτε τις κατά την εκκίνηση του server(s).
