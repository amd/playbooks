# Ρύθμιση Πλατφόρμας

Αυτό το έγγραφο περιγράφει τις αναμενόμενες ρυθμίσεις πλατφόρμας για την εκτέλεση αυτού του playbook.

## Απαιτούμενες Εφαρμογές/Πλαίσια Εργασίας

### Windows/Linux

Το GAIA θα πρέπει να είναι προεγκατεστημένο χρησιμοποιώντας τις οδηγίες που παρέχονται στον [Οδηγό Εγκατάστασης GAIA](../../dependencies/gaia.md).

Ο Lemonade Server θα πρέπει να είναι προεγκατεστημένος χρησιμοποιώντας τις οδηγίες που παρέχονται στον [Οδηγό Εγκατάστασης Lemonade](../../dependencies/lemonade.md).

## Απαιτούμενα Μοντέλα

### Windows/Linux

Ο Hardware Advisor Agent χρησιμοποιεί το **Qwen3-Coder-30B** για τη λογική συλλογιστική του πράκτορα. Αυτό το μοντέλο κατεβαίνει αυτόματα κατά τη διάρκεια του `gaia init`. Δεν απαιτείται χειροκίνητη λήψη μοντέλων.
