# Ρύθμιση πλατφόρμας

Αυτό το έγγραφο περιγράφει τις αναμενόμενες ρυθμίσεις πλατφόρμας για την εκτέλεση αυτού του playbook.

## Απαιτούμενες εφαρμογές/πλαίσια εργασίας

### Windows/Linux

- Ο **Lemonade Server** πρέπει να είναι εγκατεστημένος ακολουθώντας τον
  [οδηγό εγκατάστασης Lemonade](https://lemonade-server.ai/docs/guide/install/).
- **Node.js 22.12 ή νεότερη έκδοση** και `npm`, που χρησιμοποιούνται από το CLI `agent-canvas` και τους διακομιστές MCP
  που εκκινούνται με `npx`.
- **uv**, ο διαχειριστής πακέτων Python που χρησιμοποιεί το Agent Canvas για τη διαχείριση του περιβάλλοντος
  διακομιστή του agent. Εγκαταστήστε το από τον
  [οδηγό εγκατάστασης uv](https://docs.astral.sh/uv/getting-started/installation/).

## Απαιτούμενα μοντέλα

### Windows/Linux

Το ακόλουθο μοντέλο πρέπει να είναι διαθέσιμο στον Lemonade Server πριν από την έναρξη
του playbook.

| Τύπος μοντέλου | Αναγνωριστικό μοντέλου | Σημειώσεις |
| --- | --- | --- |
| Μοντέλο συνομιλίας GGUF | `Qwen3.6-35B-A3B-GGUF` | Εξυπηρετείται από τον Lemonade Server στο `http://127.0.0.1:13305/api/v1`. Χρησιμοποιήστε ένα μικρότερο μοντέλο GGUF σε συσκευές με λιγότερα από 32 GB μνήμης. |

Ξεκινήστε το μοντέλο με:

```bash
lemonade config set llamacpp.backend=vulkan
lemonade config set ctx_size=65536
lemonade run "Qwen3.6-35B-A3B-GGUF"
```

## Εξωτερικά διαπιστευτήρια

Αυτό το playbook απαιτεί:

- Ένα διακριτικό (token) GitHub με δικαίωμα ανάγνωσης στο αποθετήριο που συνοψίζεται.
- Ένα διακριτικό bot Slack με δικαιώματα `chat:write` και ανάγνωσης καναλιού.
- Ένα αναγνωριστικό ομάδας Slack (team ID) και το αναγνωριστικό του καναλιού Slack-στόχου.
