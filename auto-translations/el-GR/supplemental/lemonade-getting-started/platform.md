# Διαμόρφωση Πλατφόρμας — Lemonade Local AI

Αυτό το έγγραφο περιγράφει το προεγκατεστημένο λογισμικό, τις διαδρομές μοντέλων και τις προαπαιτούμενες ρυθμίσεις ανά πλατφόρμα που προϋποθέτει αυτό το playbook.

## Προεγκατεστημένο Λογισμικό

| Λογισμικό | Έκδοση | Σκοπός |
|----------|---------|---------|
| Lemonade Server | Τελευταία έκδοση | Τοπικός διακομιστής LLM με API συμβατό με OpenAI |
| Python | 3.10–3.13 | Απαιτείται για το παράδειγμα Python client του OpenAI |

## Προεπιλεγμένη Αποθήκευση Μοντέλων

Τα μοντέλα που λαμβάνονται μέσω του Lemonade αποθηκεύονται σύμφωνα με την προδιαγραφή Hugging Face Hub:

| Πλατφόρμα | Προεπιλεγμένη Διαδρομή |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

Για να αλλάξετε τη θέση αποθήκευσης, ορίστε τη μεταβλητή περιβάλλοντος `HF_HOME`.

## Απαιτήσεις Υλικού

| Στόχος Υλικού | Απαιτήσεις |
|----------------|-------------|
| **CPU** | Οποιοσδήποτε σύγχρονος επεξεργαστής x86-64 (AMD ή Intel) |
| **GPU (Vulkan)** | Οποιοδήποτε GPU με υποστήριξη προγράμματος οδήγησης Vulkan |
| **GPU (ROCm)** | AMD Radeon RX σειράς 7000/9000 ή Radeon PRO W7000 σειράς· AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | Επεξεργαστής AMD Ryzen AI 300 σειράς, Windows 11 |

## Απαιτήσεις Δικτύου

- Απαιτείται σύνδεση στο διαδίκτυο για την αρχική λήψη μοντέλου (1–25 GB ανάλογα με το μοντέλο)
- Δεν απαιτείται διαδίκτυο μετά τη λήψη των μοντέλων
