# Διαμόρφωση Πλατφόρμας — Lemonade Local AI

Αυτό το έγγραφο περιγράφει το προεγκατεστημένο λογισμικό, τις διαδρομές μοντέλων και τις προαπαιτούμενες προϋποθέσεις ανά πλατφόρμα που θεωρούνται δεδομένες σε αυτόν τον οδηγό.

## Προεγκατεστημένο Λογισμικό

| Λογισμικό | Έκδοση | Σκοπός |
|----------|---------|---------|
| Lemonade Server | Τελευταία έκδοση | Τοπικός διακομιστής LLM με API συμβατό με OpenAI |
| Python | 3.10–3.13 | Απαιτείται για το παράδειγμα του πελάτη Python της OpenAI |

## Προεπιλεγμένη Αποθήκευση Μοντέλων

Τα μοντέλα που κατεβαίνουν μέσω του Lemonade αποθηκεύονται χρησιμοποιώντας την προδιαγραφή του Hugging Face Hub:

| Πλατφόρμα | Προεπιλεγμένη Διαδρομή |
|----------|-------------|
| Windows | `%USERPROFILE%\.cache\huggingface\hub\` |
| Linux | `~/.cache/huggingface/hub/` |

Για να αλλάξετε την τοποθεσία αποθήκευσης, ορίστε τη μεταβλητή περιβάλλοντος `HF_HOME`.

## Απαιτήσεις Υλικού

| Στόχος Υλικού | Απαιτήσεις |
|----------------|-------------|
| **CPU** | Οποιοσδήποτε σύγχρονος επεξεργαστής x86-64 (AMD ή Intel) |
| **GPU (Vulkan)** | Οποιαδήποτε GPU με υποστήριξη προγράμματος οδήγησης Vulkan |
| **GPU (ROCm)** | AMD Radeon RX 7000/9000 series ή Radeon PRO W7000 series· AMD Ryzen AI MAX+ Pro 395 |
| **NPU** | Επεξεργαστής AMD Ryzen AI 300 series, Windows 11 |

## Απαιτήσεις Δικτύου

- Απαιτείται σύνδεση στο διαδίκτυο για την αρχική λήψη του μοντέλου (1–25 GB ανάλογα με το μοντέλο)
- Δεν απαιτείται σύνδεση στο διαδίκτυο μετά τη λήψη των μοντέλων
