### n8n

<!-- @os:windows -->

1. Öppna PowerShell eller Kommandotolken
2. Installera n8n globalt med npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Installera n8n globalt med npm:
```bash
npm install -g n8n
```

> **Obs**: Se [n8n-dokumentationen](https://docs.n8n.io/hosting/installation/npm/) för fler installationsalternativ.

<!-- @os:end -->
