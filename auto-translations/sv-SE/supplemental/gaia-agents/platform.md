# Plattformskonfiguration

Detta dokument beskriver de förväntade plattformskonfigurationerna för att köra denna spelbok.

## Nödvändiga appar/ramverk

### Windows/Linux

GAIA bör vara förinstallerat med hjälp av instruktionerna i [GAIA-installationsguiden](../../dependencies/gaia.md).

Lemonade Server bör vara förinstallerat med hjälp av instruktionerna i [Lemonade-installationsguiden](../../dependencies/lemonade.md).

## Nödvändiga modeller

### Windows/Linux

Hardware Advisor Agent använder **Qwen3-Coder-30B** för agentresonemang. Denna modell laddas ned automatiskt under `gaia init`. Inga manuella modellnedladdningar krävs.
