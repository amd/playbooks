#### ROCm

**Dodajte trenutnega uporabnika v skupini render in video.** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**Znova zaženite sistem, da uveljavite nastavitve.**
```bash
sudo reboot
```

**Namestite ROCm v ustvarjenem navideznem okolju.**
> **Opomba**: Pred nadaljevanjem se prepričajte, da je navidezno okolje aktivno.
