### n8n

<!-- @os:windows -->

1. Odprite PowerShell ali ukazni poziv
2. Namestite n8n globalno z uporabo npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Namestite n8n globalno z uporabo npm:
```bash
npm install -g n8n
```

> **Opomba**: Za več možnosti namestitve glejte [dokumentacijo n8n](https://docs.n8n.io/hosting/installation/npm/).

<!-- @os:end -->
