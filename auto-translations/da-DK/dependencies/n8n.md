### n8n

<!-- @os:windows -->

1. Åbn PowerShell eller Kommandoprompt
2. Installer n8n globalt ved hjælp af npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Installer n8n globalt ved hjælp af npm:
```bash
npm install -g n8n
```

> **Bemærk**: Se [n8n-dokumentationen](https://docs.n8n.io/hosting/installation/npm/) for flere installationsmuligheder.

<!-- @os:end -->
