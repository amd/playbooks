### n8n

<!-- @os:windows -->

1. Otvorite PowerShell ili Command Prompt
2. Instalirajte n8n globalno koristeći npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Instalirajte n8n globalno koristeći npm:
```bash
npm install -g n8n
```

> **Napomena**: Pogledajte [n8n dokumentaciju](https://docs.n8n.io/hosting/installation/npm/) za više opcija instalacije.

<!-- @os:end -->
