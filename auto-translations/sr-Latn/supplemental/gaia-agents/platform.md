# Konfiguracija platforme

Ovaj dokument opisuje očekivane konfiguracije platforme za pokretanje ovog priručnika.

## Potrebne aplikacije/okviri

### Windows/Linux

GAIA treba biti unapred instalirana prema uputstvima datim u [Vodiču za instalaciju GAIA](../../dependencies/gaia.md).

Lemonade Server treba biti unapred instaliran prema uputstvima datim u [Vodiču za instalaciju Lemonade](../../dependencies/lemonade.md).

## Potrebni modeli

### Windows/Linux

Agent za hardverske savete koristi **Qwen3-Coder-30B** za rezonovanje agenta. Ovaj model se automatski preuzima tokom `gaia init`. Nije potrebno ručno preuzimanje modela.
