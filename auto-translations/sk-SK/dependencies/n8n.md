### n8n

<!-- @os:windows -->

1. Otvorte PowerShell alebo príkazový riadok
2. Nainštalujte n8n globálne pomocou npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Nainštalujte n8n globálne pomocou npm:
```bash
npm install -g n8n
```

> **Poznámka**: Ďalšie možnosti inštalácie nájdete v [dokumentácii n8n](https://docs.n8n.io/hosting/installation/npm/).

<!-- @os:end -->
