# תצורת פלטפורמה

מסמך זה מתאר את תצורות הפלטפורמה הצפויות להפעלת ה-playbook הזה.

## אפליקציות/מסגרות נדרשות

### Windows/Linux

יש להתקין את GAIA מראש בהתאם להוראות המפורטות ב[מדריך התקנת GAIA](../../dependencies/gaia.md).

יש להתקין את Lemonade Server מראש בהתאם להוראות המפורטות ב[מדריך התקנת Lemonade](../../dependencies/lemonade.md).

## מודלים נדרשים

### Windows/Linux

סוכן יועץ החומרה משתמש ב-**Qwen3-Coder-30B** לצורך הסקת מסקנות של הסוכן. מודל זה מורד אוטומטית במהלך `gaia init`. אין צורך בהורדות מודל ידניות.
