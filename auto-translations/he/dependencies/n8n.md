### n8n

<!-- @os:windows -->

1. פתח את PowerShell או שורת הפקודה
2. התקן את n8n באופן גלובלי באמצעות npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

התקן את n8n באופן גלובלי באמצעות npm:
```bash
npm install -g n8n
```

> **הערה**: ראה [תיעוד n8n](https://docs.n8n.io/hosting/installation/npm/) לאפשרויות התקנה נוספות.

<!-- @os:end -->
