### n8n

<!-- @os:windows -->

1. פתחו את PowerShell או את Command Prompt
2. התקינו את n8n גלובלית באמצעות npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

התקינו את n8n גלובלית באמצעות npm:
```bash
npm install -g n8n
```

> **הערה**: ראו את [תיעוד n8n](https://docs.n8n.io/hosting/installation/npm/) לאפשרויות התקנה נוספות.

<!-- @os:end -->
