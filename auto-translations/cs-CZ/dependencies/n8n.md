### n8n

<!-- @os:windows -->

1. Otevřete PowerShell nebo příkazový řádek
2. Nainstalujte n8n globálně pomocí npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Nainstalujte n8n globálně pomocí npm:
```bash
npm install -g n8n
```

> **Poznámka**: Další možnosti instalace naleznete v dokumentaci [n8n Documentation](https://docs.n8n.io/hosting/installation/npm/).

<!-- @os:end -->
