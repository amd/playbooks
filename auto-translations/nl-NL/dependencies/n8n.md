### n8n

<!-- @os:windows -->

1. Open PowerShell of Opdrachtprompt
2. Installeer n8n globaal met npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Installeer n8n globaal met npm:
```bash
npm install -g n8n
```

> **Opmerking**: Zie [n8n Documentatie](https://docs.n8n.io/hosting/installation/npm/) voor meer installatieopties.

<!-- @os:end -->
