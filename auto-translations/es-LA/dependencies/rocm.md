#### ROCm

**Agrega el usuario actual a los grupos render y video.** 
```bash
sudo usermod -a -G render,video $LOGNAME
```

**Reinicia tu sistema para aplicar la configuración.**
```bash
sudo reboot
```

**Instala ROCm en el entorno virtual creado.**
> **Nota**: Asegúrate de que el entorno virtual esté activo antes de continuar.
