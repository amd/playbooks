### n8n

<!-- @os:windows -->

1. Abre PowerShell o el Símbolo del sistema
2. Instala n8n globalmente usando npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Instala n8n globalmente usando npm:
```bash
npm install -g n8n
```

> **Nota**: Consulta la [Documentación de n8n](https://docs.n8n.io/hosting/installation/npm/) para más opciones de instalación.

<!-- @os:end -->
