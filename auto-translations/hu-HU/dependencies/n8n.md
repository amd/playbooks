### n8n

<!-- @os:windows -->

1. Nyisd meg a PowerShell-t vagy a Parancssort
2. Telepítsd az n8n-t globálisan az npm segítségével:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Telepítsd az n8n-t globálisan az npm segítségével:
```bash
npm install -g n8n
```

> **Megjegyzés**: További telepítési lehetőségekért lásd az [n8n dokumentációt](https://docs.n8n.io/hosting/installation/npm/).

<!-- @os:end -->
