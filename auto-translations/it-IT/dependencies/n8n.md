### n8n

<!-- @os:windows -->

1. Apri PowerShell o il Prompt dei comandi
2. Installa n8n globalmente usando npm:
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Installa n8n globalmente usando npm:
```bash
npm install -g n8n
```

> **Nota**: Consulta la [Documentazione di n8n](https://docs.n8n.io/hosting/installation/npm/) per ulteriori opzioni di installazione.

<!-- @os:end -->
