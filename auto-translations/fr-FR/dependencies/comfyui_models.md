### Modèles ComfyUI

<!-- @device:halo_box -->
> **Remarque :** Si les modèles sont déjà disponibles dans ComfyUI, vous pouvez ignorer cette section. Sinon, suivez les étapes ci-dessous pour les télécharger.
<!-- @device:end -->

Si vous avez précédemment supprimé des modèles ComfyUI pré-téléchargés ou si vous souhaitez les télécharger pour la première fois, appuyez simplement sur le bouton `Download` pour chaque modèle lorsque vous êtes invité à le faire en cas de détection de modèles manquants.
Vous devrez peut-être placer manuellement les fichiers de modèle aux emplacements appropriés.

<!-- @device:halo_box -->
<!-- @os:linux -->
> **Remarque :** Sur l'AMD Ryzen™ AI Halo, ComfyUI s'exécute dans un conteneur préconstruit. Placez tout fichier de modèle téléchargé manuellement sous `~/.local/share/ComfyUI/models` (dans le sous-dossier correspondant `diffusion_models`, `text_encoders`, ou `vae`) afin que ComfyUI conteneurisé puisse le trouver.
<!-- @os:end -->
<!-- @device:end -->
