### Modèles ComfyUI

<!-- @device:halo_box -->
> **Remarque :** Si les modèles sont déjà disponibles dans ComfyUI, vous pouvez ignorer cette section. Sinon, suivez les étapes ci-dessous pour les télécharger.
<!-- @device:end -->

Si vous avez précédemment supprimé des modèles ComfyUI préalablement téléchargés ou si vous souhaitez les télécharger pour la première fois, appuyez simplement sur le bouton `Download` pour chaque modèle lorsque vous êtes invité à le faire suite à la détection de modèles manquants.
Il se peut que vous deviez placer manuellement les fichiers de modèles aux emplacements appropriés.

<!-- @device:halo_box -->
<!-- @os:linux -->
> **Remarque :** Sur l'AMD Ryzen™ AI Halo, ComfyUI s'exécute dans un conteneur préconstruit. Placez tout fichier de modèle téléchargé manuellement sous `~/.local/share/ComfyUI/models` (dans le sous-dossier correspondant `diffusion_models`, `text_encoders` ou `vae`) afin que le ComfyUI conteneurisé puisse le trouver.
<!-- @os:end -->
<!-- @device:end -->
