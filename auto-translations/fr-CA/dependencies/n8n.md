### n8n

<!-- @os:windows -->

1. Ouvrez PowerShell ou l'invite de commandes
2. Installez n8n de façon globale avec npm :
```cmd
npm install -g n8n
```

<!-- @os:end -->

<!-- @os:linux -->

Installez n8n de façon globale avec npm :
```bash
npm install -g n8n
```

> **Remarque** : consultez la [documentation de n8n](https://docs.n8n.io/hosting/installation/npm/) pour connaître d'autres options d'installation.

<!-- @os:end -->
