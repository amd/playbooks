### Modèles ComfyUI

Si vous avez déjà supprimé des modèles ComfyUI pré-téléchargés ou si vous souhaitez les télécharger pour la première fois, il suffit d'appuyer sur le bouton `Download` de chaque modèle lorsqu'un message vous indique que des modèles manquants ont été détectés.
Il se peut que vous deviez placer manuellement les fichiers de modèles aux emplacements appropriés.
