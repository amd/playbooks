### Modèles ComfyUI

<!-- @device:halo_box -->
> **Remarque :** si les modèles sont déjà disponibles dans ComfyUI, vous pouvez ignorer cette section. Sinon, suivez les étapes ci-dessous pour les télécharger.
<!-- @device:end -->

Si vous avez déjà supprimé des modèles ComfyUI préalablement téléchargés ou si vous souhaitez les télécharger pour la première fois, appuyez simplement sur le bouton `Download` pour chaque modèle lorsqu'un message vous indique que des modèles manquants ont été détectés.
Il se peut que vous deviez placer manuellement les fichiers de modèles aux bons emplacements.

<!-- @device:halo_box -->
<!-- @os:linux -->
> **Remarque :** sur l'AMD Ryzen™ AI Halo, ComfyUI s'exécute dans un conteneur préconfiguré. Placez tout fichier de modèle téléchargé manuellement sous `~/.local/share/ComfyUI/models` (dans le sous-dossier correspondant `diffusion_models`, `text_encoders` ou `vae`) afin que ComfyUI, exécuté dans le conteneur, puisse les trouver.
<!-- @os:end -->
<!-- @device:end -->
