Before starting, check whether your system has the **AMD Install Manager**. If it does, open it, select the **AI Bundle**, and go to the **Software** tab.

Select **Sync to recommended** to bring the listed AI applications, development frameworks, and graphics driver up to the versions AMD recommends for your hardware. Much of what this playbook installs is covered there, so syncing first can save you several manual steps and keeps your versions consistent.

<p align="center">
  <img src="/api/dependencies/assets/ai-bundle/windows.png" alt="AMD Install Manager — AI Bundle page showing the Software tab and the Sync to recommended button" width="600"/>
</p>

This step is optional. If you don't have the AMD Install Manager, or you'd rather install everything yourself, continue with the steps below as written.
